class UpdateQuotesCatalogTask

Parents
Task

Brief

The Update Quotes Catalog task.

Details

The task must be used every time you are going to prepare or receive quotes in order to be sure that the client has the most recent version of the catalog.

You can check whether the update catalog operation is actually required using the QuotesManager.isQuotesCatalogUpdated() method. If this method returns true, the task will have no effect (but there is nothing wrong to run this task in this case).

The result of the task will be reported into the instance of IUpdateQuotesCatalogCallback associated with the task when the task is created.

The task has no intermediate result, it only changes the internal Quotes Manager data.

Use QuotesManager.createUpdateQuotesCatalogTask() to create the task.

The type defined in the quotesmgr2.jar. The package is com.candleworks.quotesmgr.
