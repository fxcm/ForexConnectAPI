static public method CandlePeriod.parsePeriod

Brief

Parses the name of the timeframe into time unit and length.

Declaration
Java
static boolean  parsePeriod (String name, AtomicReference<CandlePeriod.Unit> unit, Integer unitLength) throws java.lang.IllegalArgumentException

Parameters
name

The name of the timeframe.

See also What is timeframe? for an explanation of the timeframe names.
unit

[output] The time measurement unit.
unitLength

[output] The length of the period in units.

Exceptions
java.lang.IllegalArgumentException

The exception is thrown if any argument is null.
