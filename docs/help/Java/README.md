# Java Help

This folder contains 1,538 API reference pages. GitHub's file browser only lists
the first 1,000 files per directory, so some entries above won't be shown here.

To see or download all files:

- **Clone the repo** — gets everything, no limit:
  ```
  git clone https://github.com/fxcm/ForexConnectAPI.git
  ```
- **Jump to a specific file** — press `t` on any repo page (or use the magnifying
  glass) to search filenames instead of scrolling the list.
- **Download a ZIP** — use the green "Code" button on the repo's main page.
