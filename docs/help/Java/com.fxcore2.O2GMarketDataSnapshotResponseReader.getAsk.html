public method O2GMarketDataSnapshotResponseReader.getAsk

Brief

Gets the ask price of a tick.

Declaration
Java
double  getAsk (int index)

Parameters
index

The index of a tick in the reader. The index must be between 0 and size() - 1.

Details

In the case of FX instruments, the returned value is expressed in the counter currency of an instrument per one unit of the base currency.
In the case of CFD instruments, the returned value is expressed in the native currency of an instrument per one contract.

The method is applicable only if the returned value of the isBar method is false.
