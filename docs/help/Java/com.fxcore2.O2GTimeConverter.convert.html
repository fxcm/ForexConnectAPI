public method O2GTimeConverter.convert

Brief

Converts a calendar value to a specified time zone.

Declaration
Java
java.util.Calendar  convert (java.util.Calendar date, O2GTimeConverterTimeZone to)

Parameters
date

A calendar value to convert.
to

A time zone to convert to.

Details

Before calling the method, an instance of the O2GTimeConverter class must be obtained by using the O2GSession.getTimeConverter method. For example,

O2GTimeConverter converter = mSession.getTimeConverter();

Example

Convert calendar value into the LOCAL time zone [show]

Convert calendar value into the LOCAL time zone [hide]

O2GTimeConverter converter = mSession.getTimeConverter();
Calendar calDate = Calendar.getInstance();
System.out.println("Original Timezone is: " + calDate.getTimeZone().getID());
calDate = converter.convert(calDate, O2GTimeConverterTimeZone.LOCAL);
System.out.println("Converted Timezone is: " + calDate.getTimeZone().getID());
