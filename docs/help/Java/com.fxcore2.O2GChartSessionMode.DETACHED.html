static public field O2GChartSessionMode.DETACHED

Brief

The system uses the separate session for chart server.

Details

Work in the separate chart channel mode. This mode is useful if you develop GUI using ForexConnect. This mode allows to enable/disable trading and charts independently of one another.
If the system is unable to connect to chart server, the login process goes without chart session. In this case you are able to trade, but unable to send requests to the chart server.
Chart session may be switched to RECONNECTING state(O2GChartSessionStatusCode.RECONNECTING) without reconnecting of the trade session.
Separate statuses for the chart session can be received using IO2GChartSessionStatus interface. Trading session status does not depend on chart session status.
Programs developed previously required to be changed (details: IO2GChartSessionStatus).
