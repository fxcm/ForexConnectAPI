interface IO2GRolloverProviderListener

Brief

The interface provides the method signature to process notifications about rollover updating.

Details

The interface must be implemented by an application in order to process notifications about the rollover provider status updating.

Implementation

To use the onStatusChanged method of the IO2GRolloverProviderListener interface, create a class that implements the interface. For example,

public class RolloverProviderListener implements IO2GRolloverProviderListener {...}

In your application, create an instance of the class that implements the interface. For example,

RolloverProviderListener rolloverProviderListener = new RolloverProviderListener ();

This instance must be subscribed to rollover provider events by using the subscribe method as follows:

rolloverProvider.subscribe(rolloverProviderListener);

Before logging out, unsubscribe the listener by using the unsubscribe method as follows:

rolloverProvider.unsubscribe(rolloverProviderListener);

Public Methods

onStatusChanged

The method processes notifications about rollover status updating.
