class O2GOffersTable

Parents
O2GTable

Brief

The class keeps in memory the up-to-date information about offers.

Details

The class is an in-memory representation of the Offers table.
In order to keep this representation in sync with the trading server, you must instantiate the class and listen to the updates coming from the trading server. The class provides methods to find individual offers, represented by the O2GOfferTableRow.

Prerequisites

The class is available only through the use of the O2GTableManager. An O2GTableManager object must have the O2GTableManagerStatus.TABLES_LOADED status.
For complete instructions on the table manager usage, see the How to use table manager in ForexConnect API section.

Instantiating the class

In order to get offers information for the first time, you must obtain an instance of the class by calling the O2GTableManager.getTable method with the O2GTableType.OFFERS argument. For example,

O2GOffersTable offersTable = (O2GOffersTable)tableManager.getTable(O2GTableType.OFFERS);

Receiving notifications about the Offers table updates

In order to keep the O2GOffersTable data current, your application must listen to the Offers table updates coming from the trading server. These updates represent inserts into the table and changes of the offer information. An instance of the class implementing the IO2GTableListener interface must be subscribed to the table updates. Subscription for each update type is done individually. Before the logout, you must unsubscribe the listener from every update type separately. The table below shows the subscription/unsubsription syntax for the O2GOffersTable:

Update type

Subscribe syntax

Unsubscribe syntax

INSERT

offersTable.subscribeUpdate(O2GTableUpdateType.INSERT, tableListener);

offersTable.unsubscribeUpdate(O2GTableUpdateType.INSERT, tableListener);

UPDATE

offersTable.subscribeUpdate(O2GTableUpdateType.UPDATE, tableListener);

offersTable.unsubscribeUpdate(O2GTableUpdateType.UPDATE, tableListener);

Note: Offers can be deleted only when the market is closed. Therefore, you do not receive updates of the DELETE type during the trading session and there is no need to subscribe to it.

Example

    // Get the instance of table manager
    O2GTableManager tableManager = mSession.getTableManager();
    while (tableManager.getStatus() != O2GTableManagerStatus.TABLES_LOADED &
           tableManager.getStatus() != O2GTableManagerStatus.TABLES_LOAD_FAILED) {
        Thread.sleep(50);
    }
 
    // Get offers information
    if (tableManager.getStatus() == O2GTableManagerStatus.TABLES_LOADED) {
        O2GOffersTable offersTable = (O2GOffersTable)tableManager.getTable(O2GTableType.OFFERS);
        for (int i = 0; i < offersTable.size(); i++) {
            O2GOfferTableRow offer = offersTable.getRow(i);
            System.out.println("Instrument: " + offer.getInstrument() +
                               " Bid = " + offer.getBid() +
                               " Ask = " + offer.getAsk() +
                               " PipCost = " + offer.getPipCost());
        }
 
        // Subscribe table listener
        TableListener tableListener = new TableListener();
        offersTable.subscribeUpdate(O2GTableUpdateType.UPDATE, tableListener);
        Thread.sleep(1000);
        offersTable.unsubscribeUpdate(O2GTableUpdateType.UPDATE, tableListener);
    }
 
    // Implementation of IO2GTableListener interface public method onChanged
    public void onChanged(String rowID, O2GRow rowData) {
        O2GOfferTableRow offer = (O2GOfferTableRow)(rowData);
        System.out.println("Offer information changed " + rowID);
        System.out.println("Instrument: " + offer.getInstrument() +
                           " Bid = " + offer.getBid() +
                           " Ask = " + offer.getAsk() +
                           " PipCost = " + offer.getPipCost());
    }
