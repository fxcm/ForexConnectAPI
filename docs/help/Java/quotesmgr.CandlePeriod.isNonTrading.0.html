static public method CandlePeriod.isNonTrading

Brief

Checks whether the specified date/time belongs to a regular schedule of non-trading hours.

Declaration
Java
static boolean  isNonTrading (java.util.Calendar date, int startHourOffset, java.util.Calendar lastend) throws java.lang.IllegalArgumentException

Parameters
date

The date/time to check.
startHourOffset

The offset of the trading day start against the calendar day midnight, expressed in hours.

See the class documentation for discussion of this parameter.
lastend

[output] The date and time when a non-trading period started.

Exceptions
java.lang.IllegalArgumentException

The exception is thrown if any argument is null.

Details

During a regular schedule, the market is closed from the end of the trading day of Friday (17:00NYT of Friday) to the start of the trading day of Monday (17:00NYT of Sunday).
