public method O2GResponseReaderFactory.createOffersTableReader

Brief

Creates a reader to process a response to a request for initial offer information.

Declaration
Java
O2GOffersTableResponseReader  createOffersTableReader (O2GResponse response)

Parameters
response

A response object. The response must have the GET_OFFERS type.

Details

The method returns an instance of the reader or null in the case of the response having a wrong type or if it is broken.
