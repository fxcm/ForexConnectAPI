static public method PriceHistoryCommunicatorFactory.createCommunicator

Brief

Creates an instance of the Price History API communicator.

Declaration
Java
static IPriceHistoryCommunicator  createCommunicator (O2GSession o2gSession, String quotesManagerDataPath) throws java.lang.IllegalArgumentException, PriceHistoryError

Parameters
o2gSession

An instance of the ForexConnect trading session.

The session must not be logged in yet at the moment this method is called.
quotesManagerDataPath

The local path where the Quotes Manager API must store its cache data.

Exceptions
java.lang.IllegalArgumentException

The exception is thrown if any parameter is null.
PriceHistoryError

The exception is thrown in case the price communicator failed to create.

Details

The instance of the price history communicator does not become ready immediately upon creation. In order to make it usable, the application must:

  • Log in the trading session.

  • Then wait until the price communicator object switches into the ready state.

Example [hide]

import com.fxcore2.*;
import com.candleworks.pricehistorymgr.*;
 
public class MyClass implements IO2GSessionStatus, IPriceHistoryCommunicatorListener
{
    ...
    private O2GSession mTradingSession;
    private IPriceHistoryCommunicator mPriceHistoryCommunicator;
 
    ...
    void initialize(String userName, String password, String url, String terminal, String cachePath)
    {
        try {
            //create the trading session and subscribe for it's event
            mTradingSession = O2GTransport.createSession();
            mTradingSession.subscribeSessionStatus(this);
 
            //create a price history communicator and subscribe for its events
            mPriceHistoryCommunicator = PriceHistoryCommunicatorFactory.createCommunicator(mTradingSession, cachePath);
            mPriceHistoryCommunicator.addListener(this);
 
            //Start login process
            mTradingSession.login(userName, password, url, terminal);
        } catch(Exception e) {
            //process error
 
        }
    }
}
