public method IPriceHistoryCommunicator.createRequest

Brief

Creates a new price history request.

Declaration
Java
IPriceHistoryCommunicatorRequest  createRequest (String instrument, O2GTimeframe timeframe, java.util.Calendar from, java.util.Calendar to, int quotesCount) throws java.lang.IllegalStateException, java.lang.IllegalArgumentException, PriceHistoryError

Parameters
instrument

The instrument name. The instrument must be one of the instruments the ForexConnect session is subscribed to.

To check the list of the instruments, use the offers table. The name of the instrument is kept in Instrument column of the table.
timeframe

The timeframe of the history.

To get the list of standard supported timeframes, get an instance of O2GTimeframeCollection. Or you can use a custom timeframe that can be created using ITimeframeFactory.
from

Date/time of the oldest bar/tick in the history.

Use null in order to get quotesCount bars ending at to date/time.

The date/time must be in the UTC time zone.
to

Date/time of the most recent bar/tick in the history.

Use null to get the collection up to the most recent ("now") bar/tick.

The date/time must be in the UTC time zone.
quotesCount

The maximum number of bars in the history.

Use -1 to get all bars between from and to date. In case -1 is used, the from date must not be null.

Exceptions
java.lang.IllegalStateException

The exception is thrown if the PriceHistoryCommunicator is already disposed.
java.lang.IllegalArgumentException

The exception is thrown if instrument or timeframe parameter is null.
PriceHistoryError

The exception is thrown if the request cannot be created.

Details

The method only creates the request but does not send it. Use sendRequest() to send the request to the server.

import com.fxcore2.*;
import com.candleworks.pricehistorymgr.*;
 
import java.util.Calendar;
import java.util.TimeZone;
 
class MyClass
{
    ...
    private O2GSession mTradingSession;
    private IPriceHistoryCommunicator mPriceHistoryCommunicator;
 
    ...
    void myMethod()
    {
        try {
            O2GRequestFactory factory = mTradingSession.getRequestFactory();
            // will be null if you are not logged in
            if (factory == null)
            {
                //process error
                return;
            }
            O2GTimeframeCollection timeframes = factory.getTimeFrameCollection();
            O2GTimeframe timeframe = timeframes.get("m1");
 
            Calendar dateTo = Calendar.getInstance(TimeZone.getTimeZone("UTC"));
            Calendar dateFrom = Calendar.getInstance(TimeZone.getTimeZone("UTC"));
 
            dateTo.set(Calendar.HOUR_OF_DAY, 0);
            dateTo.set(Calendar.MINUTE, 0);
            dateTo.set(Calendar.SECOND, 0);
            dateTo.set(Calendar.MILLISECOND, 0);
 
            dateFrom.setTime(dateTo.getTime());
            dateFrom.add(Calendar.DAY_OF_MONTH, -1);
 
            String instrument = "EUR/USD";
 
            IPriceHistoryCommunicatorRequest request = mPriceHistoryCommunicator.createRequest(instrument, timeframe, dateFrom, dateTo, -1);
            mPriceHistoryCommunicator.sendRequest(request);
        } catch (IllegalStateException error) {
            //process errror
        } catch (IllegalArgumentException error) {
            //process errror
        } catch(PriceHistoryError error){
            //process error
 
        }
   }
}
