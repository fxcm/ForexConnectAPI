public method O2GOrdersTable.setTableEventsFilter

Brief

This method allows setting a filter to receive only trading events and not receive events caused by data recalculation.

Declaration
C#
void  setTableEventsFilter (O2GTableEventsFilter tableEventsFilter)

Parameters
tableEventsFilter

The type of events filtration. Possible values are listed in O2GTableEventsFilter.

Details

There are two types of events:

1. Real trading events, for example, position opening or price change. These events are received from the trade server and the system sends them to subscribers.
2. Recalculation events. Some values in tables are calculated by the system. For example PL of the trade is calculated using the open and the current market prices. When receiving trading events, the system recalculates affected values in the tables and sends events to subscribers.

The method getTableEventsFilter allows to return the set value.
