public property O2GTradeRow.OpenOrderID

Brief

Gets the unique identification number of the order the position is opened by.

Declaration
C#
string  OpenOrderID get;

Details

The returned value is unique within the same database that stores the account the order is placed on. For example, MINIDEMO or U100D1. The uniqueness of the order itself is ensured by the combination of the database ID and the returned value of this method.
