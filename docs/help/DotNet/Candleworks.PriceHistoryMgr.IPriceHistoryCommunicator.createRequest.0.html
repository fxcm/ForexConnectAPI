public method IPriceHistoryCommunicator.createRequest

Brief

Creates a new price history request.

Declaration
C#
IPriceHistoryCommunicatorRequest  createRequest (string instrument, fxcore2.O2GTimeframe timeframe, DateTime from, DateTime to, int quotesCount)

Parameters
instrument

The instrument name. The instrument must be one of the instruments the ForexConnect session is subscribed to.

To check the list of the instruments, use the offers table. The name of the instrument is kept in Instrument column of the table.
timeframe

The timeframe of the history.

To get the list of supported timeframes, get an instance of O2GTimeframeCollection.
from

Date/time of the oldest bar/tick in the history.

Use Constants.ZERODATE in order to get quotesCount bars ending at to date/time.

The date/time must be in the UTC time zone.
to

Date/time of the most recent bar/tick in the history.

Use Constants.ZERODATE to get the collection up to the most recent ("now") bar/tick.

The date/time must be in the UTC time zone.
quotesCount

The maximum number of bars in the history.

Use -1 to get all bars between from and to date. In case -1 is used, the from date must not be Constants.ZERODATE.

Exceptions
System.InvalidOperationException

The exception is thrown if the PriceHistoryCommunicator is already disposed.
System.ArgumentNullException

The exception is thrown if the instrument or the timeframe is null.
PriceHistoryError

The exception is thrown if the request cannot be created.

Details

The method only creates the request but does not send it. Use sendRequest() to send the request to the server.

Example: Creating a 1-minute historical request for yesterday. [hide]

using System;
using fxcore2;
using Candleworks.PriceHistoryMgr;
 
class MyClass
{
    ...
    private O2GSession mTradingSession;
    private IPriceHistoryCommunicator mPriceHistoryCommunicator;
 
    ...
    void MyMethod()
    {
        O2GRequestFactory factory = mTradingSession.getRequestFactory();
        // will be null if you are not logged in
        if (factory == null)
        {
            //process error
            return;
        }
        O2GTimeframeCollection timeframes = factory.Timeframes;
        O2GTimeframe timeframe = timeframes["m1"];
 
        DateTime temp = DateTime.Now;
        DateTime to = new DateTime(temp.Year, temp.Month, temp.Day);
        DateTime from = = to.AddDays(-1);
 
        string instrument = "EUR/USD";
 
        IPriceHistoryCommunicatorRequest request = mPriceHistoryCommunicator.createRequest(instrument, timeframe, from, to, -1);
        mPriceHistoryCommunicator.sendRequest(request);
    }
}

Example: Creating a 1-day "up to now" history for the last 30 days. [hide]

using System;
using fxcore2;
using Candleworks.PriceHistoryMgr;
 
class MyClass
{
    ...
    private O2GSession mTradingSession;
    private IPriceHistoryCommunicator mPriceHistoryCommunicator;
 
    ...
    void MyMethod()
    {
        O2GRequestFactory factory = mTradingSession.getRequestFactory();
        // will be null if you are not logged in
        if (factory == null)
        {
            //process error
            return;
        }
        O2GTimeframeCollection timeframes = factory.Timeframes;
        O2GTimeframe timeframe = timeframes["D1"];
        DateTime from = DateTime.Now.AddDays(-30);
 
        string instrument = "EUR/USD";
 
        IPriceHistoryCommunicatorRequest request = mPriceHistoryCommunicator.createRequest(instrument, timeframe, from, PriceHistoryMgr.Constants.ZERODATE, -1);
        mPriceHistoryCommunicator.sendRequest(request);
    }
}
