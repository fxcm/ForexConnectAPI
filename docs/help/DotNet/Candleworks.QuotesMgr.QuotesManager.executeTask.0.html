public method QuotesManager.executeTask

Brief

Starts execution of the task.

Declaration
C#
void  executeTask (Task task)

Parameters
task

The task to be executed.

Exceptions
System.InvalidOperationException

The exception is thrown if argument is the QuotesManager is already disposed.
System.ArgumentNullException

The exception is thrown if argument is null.
QuotesManagerError

The exception is thrown if execution of the task is not supported.

Details

The following task can be created:

Task name

Creation method

Purpose

UpdateInstrumentsTask

createUpdateInstrumentsTask()

To prepare the instruments catalog before directly accessing the list of the instruments.

UpdateQuotesCatalogTask

createUpdateQuotesCatalogTask()

To prepare the quotes catalog before preparing the quotes.

PrepareQuotesTask

createPrepareQuotesTask()

To load the data into cache.

ReceiveBarQuotesTask

createReceiveBarQuotesTask()

To read the data from cache.

RemoveQuotesTask

createRemoveQuotesTask()

To remove the data from cache.

The task will be stopped when it is successfully finished, when it is failed, or when it is canceled by the cancelTask() method.

If the task produces any result, it will be passed to the callback associated with the task.
