Including Price History API in .NET to Your Application

Brief

The article discusses how to include Price History API in .NET 4.5 application.

Details

To use Price History API in your .NET 4.5 application, you should:

  1. Place your application program in the same directory where supporting dlls are located (usually the bin folder containing gsexpat.dll, pricehistorymgr.dll, quotesmgr2.dll, etc.). You can do this by either building your executable into the folder with supporting dlls or by copying the required dlls into your target directory. For example, if the folder C:\ForexConnectAPI\bin contains these libraries, a post-built event command line can look like this:

    copy C:\ForexConnectAPI\bin\*.dll "$(TargetDir)"

  2. Add net\dotnet45\pricehistorymgr_net.dll as a reference to your project.

  3. Add namespace Candleworks.PriceHistoryMgr to your project:

    using Candleworks.PriceHistoryMgr;

Price History API dependencies

If you use the Price History API, the ForexConnect API and the Quotes Manager API must be included to the application, even if you do not use or are not going to use them directly.
