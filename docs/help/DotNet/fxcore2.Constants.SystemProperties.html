class Constants.SystemProperties

Brief

Constants for ForexConnect API system properties

Constants

BASE_CRNCY

Base currency of the system

BASE_CRNCY_PRECISION

Precision of the base currency

BASE_CRNCY_SYMBOL

Symbol for the base currency (for example, $ for USD)

BASE_TIME_ZONE

Time zone of the server.

COND_DIST

Minimal distance between the rate of Stop (or Limit) order and the current market price

COND_DIST_ENTRY

Minimal distance between the rate of Entry order and the current market price

CP_170

The property shows whether the customer may close opposite positions by each other when hedging is allowed (may if the value equals "Y").

CP_171

The property shows whether the customer may open and close positions using opening orders (may in case the value equals "Y").

CP_172

The property shows whether the customer may close positions using closing orders (may in case the value equals "Y").

CP_86

The property shows whether the customer may create, change, delete entry orders, link entry orders to a contingency order, add and remove entry orders from a contingency order (may in case the value equals "Y").

CP_88

The property shows whether the customer may open and close trades (may in case the value equals "Y").

CP_89

The property shows whether the customer may change the subscription for currencies (may in case the value equals "Y").

CP_94

The property shows whether the customer may create, change and delete stop and limit orders (may in case the value equals "Y").

END_TRADING_DAY

The time of the end of a trading day in the UTC time zone

FORCE_PASSWORD_CHANGE

The property contains "Y" in case the user password is expired and must be changed immediately.

MARKET_OPEN

The property contains "Y" in case the market is open and "N" in case the market is closed.

PEGGED_STOP_LIMIT_DISABLED

If the value of this parameter is "Y", Pegged Stop/Limit orders are not supported.

QUERYDEPTH_0

The maximal number of periods that can be retrieved for a chart with the Tick period.

QUERYDEPTH_1

The maximal number of periods that can be retrieved for a chart with the m1 period.

QUERYDEPTH_2

The maximal number of periods that can be retrieved for a chart with the m5 period.

QUERYDEPTH_3

The maximal number of periods that can be retrieved for a chart with the m15 period. ]

QUERYDEPTH_4

The maximal number of periods that can be retrieved for a chart with the m30 period.

QUERYDEPTH_5

The maximal number of periods that can be retrieved for a chart with the h1 period.

QUERYDEPTH_6

The maximal number of periods that can be retrieved for a chart with the d1 period.

QUERYDEPTH_7

The maximal number of periods that can be retrieved for a chart with the w1 period.

QUERYDEPTH_8

The maximal number of periods that can be retrieved for a chart with the M1 period.

QUERYDEPTH_h2

The maximal number of periods that can be retrieved for a chart with the h2 period.

QUERYDEPTH_h3

The maximal number of periods that can be retrieved for a chart with the h3 period.

QUERYDEPTH_h4

The maximal number of periods that can be retrieved for a chart with the h4 period.

QUERYDEPTH_h6

The maximal number of periods that can be retrieved for a chart with the h6 period.

QUERYDEPTH_h8

The maximal number of periods that can be retrieved for a chart with the h8 period.

SERVER_TIME_UTC

If the value of the property equals "UTC", the server sends time as UTC time, otherwise the server sends time in the local time of the server.

SupportTickVolume

The property shows whether the tick volume is supported.

TP_170

The property shows whether the trader may close opposite positions by each other when hedging is allowed (may in case the value of the property equals "Y").

TP_171

The property shows whether the trader may open and close positions using opening orders (may in case the value of the property equals "Y").

TP_172

The property shows whether the trader may close positions using closing orders (may in case the value of the property equals "Y").

TP_86

The property shows whether the trader may create, change, delete entry orders, link entry orders to a contingency order, add and remove entry orders from a contingency order (may in case the value of the property equals "Y").

TP_88

The property shows whether the trader may open and close trades (may in case the value of the property equals "Y").

TP_89

The property shows whether the trader may change the subscription for currencies (may in case the value of the property equals "Y").

TP_94

The property shows whether the trader may create, change and delete stop and limit order (may in case the value of the property equals "Y").

TRAILING_DYNAMIC

The property shows whether the server supports dynamic trailing.

TRAILING_FLUCTUATE

The property shows whether the trailing mode is supported.

TRAILING_FLUCTUATE_PTS_MAX

The maximal value of the trailing minimal move (in pips).

TRAILING_FLUCTUATE_PTS_MIN

The minimal value of the trailing minimal move (in pips).
