public method O2GClosedTradesTable.getNextRowByMultiColumnValues

Brief

Gets the next row from O2GClosedTradesTable based on the multiple columns values.

Declaration
C#
bool  getNextRowByMultiColumnValues (string[] columnNames, O2GRelationalOperators[] conditions, object[] columnValues, O2GLogicOperators logicOperator, O2GTableIterator iterator, out O2GAccountTableRow row)

Parameters
columnNames

The array of column names in the ClosedTrades table. For example, BuySell, TradeID.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the columns specified by the columnNames parameter. For example, if you want to search the ClosedTrades table for positions by AccountID 12345 and EUR/USD instrument only, the columnNames parameter value is an array of AccountID and OfferID, and the columnValues parameter is an array of 12345 and 1.
iterator

The table iterator.
row

[out] The row fetched.

Details

This method allows finding all rows that contain all specified columns values.
If the row is not found, the method returns false.
Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.

Get closed positions by specified AccountID and OfferID from the Closed Trades table [show]

Get closed positions by specified AccountID and OfferID from the Closed Trades table [hide]

    public void EnumerateClosedTradesByAccountIDAndOfferID(string sAccountID, string sOfferID)
    {
        O2GClosedTradesTable closedTrades = (O2GClosedTradesTable)mTblMgr.getTable(O2GTableType.ClosedTrades);
        O2GTableIterator iterator = new O2GTableIterator();
        O2GClosedTradeTableRow closedTrade = null;
        string[] columnNames = new string[] { "AccountID", "OfferID" };
        object[] columnValues = new object[] { sAccountID, sOfferID };
        while (closedTrades.getNextRowByMultiColumnValues(columnNames, columnValues, iterator, out closedTrade))
        {
            Console.WriteLine("TradeID={0}, OfferID={1}, Amount={2}", closedTrade.TradeID, closedTrade.OfferID, closedTrade.Amount);
        }
    }
