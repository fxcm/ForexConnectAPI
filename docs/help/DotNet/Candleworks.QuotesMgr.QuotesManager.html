class QuotesManager

Parents
System.IDisposable

Brief

The main class of the API.

Details

This class is used for getting all information as well as creating and executing all tasks with the Quotes Manager API.

To get an instance of this class, use the IPriceHistoryCommunicator.getQuotesManager() method.

It must be the only instance of QuotesManager in the application.

The type defined in the quotesmgr2_net.dll assembly. The namespace is Candleworks.QuotesMgr.

Public Properties

mode

Gets or sets the mode of handling prices inside regular non-trading periods.

openPriceCandlesMode

Gets or sets the mode of open price candles.

Public Methods

areInstrumentsUpdated

Checks whether Quotes Manager has already successfully received or updated the instruments list.

areQuotesPrepared

Checks whether the data, required to load the history of the specified timeframe of the specified instrument in the specified range, is already loaded into the cache.

cancelTask

Cancels execution of the task.

createPrepareQuotesTask

Creates the task to load the quotes into the cache.

createReceiveBarQuotesTask

Creates the task to get quotes from the cache.

createRemoveQuotesTask

Creates the task to remove quotes from the cache.

createUpdateInstrumentsTask

Creates the task to update the instruments catalog.

createUpdateQuotesCatalogTask

Creates the task to update the catalog of the quotes for the specified instrument.

Dispose

Releases resources object have been using.

executeTask

Starts execution of the task.

getBaseTimeframes

Gets the list of base timeframes.

getDataSize

Gets the amount of data used by the cache for the specified instrument, base timeframe and year.

getInstruments

Gets the list of the instruments.

isQuotesCatalogUpdated

Checks whether Quotes Manager has already successfully received or updated the catalog of quotes for the specified instrument.
