static public method O2GTransport.setClosedHistorySize

Brief

Sets the maximum number of recent Closed Trades stored in the Closed Trades table.

Declaration
C#
static void  setClosedHistorySize (const int size)

Parameters
size

Desired number of recent Closed Trades stored in the Closed Trades table.

Details

The method setClosedHistorySize allows setting the maximum number of latest Closed Trades stored in the Closed Trades table. The specified number of entries will be downloaded during the next table refresh.
When the specified number of entries is exceeded, the oldest entry is deleted on the server.
This setting will be applied in the next created session.
