public method IPriceHistoryCommunicator::sendRequest

Brief

Sends the request to the server.

Declaration
C++
virtual bool  sendRequest (IPriceHistoryCommunicatorRequest *request, IError **error) = 0

Parameters
request

The request to be sent. The request must be created using the createRequest() method.
error

[output] If not NULL and an error occurred it will contain a pointer to a detailed error description object. It must be released by a caller after the use.

Returns

Returns true if operation is succeeded, false otherwise. See output error parameter for error description.

Details

When processing of the request is finished, the corresponding method of all listeners will be called.

The listener may be called not in the same thread which was used to send the request.
