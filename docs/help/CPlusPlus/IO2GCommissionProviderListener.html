class IO2GCommissionProviderListener

Parents
IAddRef

Brief

The interface provides the method signature to process notifications about commissions.

Details

The interface must be implemented by an application in order to process notifications about the commission provider status updating.

Implementation

To use the onChangeCommissionProviderStatus method of the IO2GCommissionProviderListener interface, create a class that implements the interface. For example,

class CommissionProviderListener : public IO2GCommissionProviderListener { }

In your application, create an instance of the class that implements the interface. For example,

CommissionProviderListener *commissionListener = new CommissionProviderListener ();

This instance must be subscribed to commission provider events by using the subscribe method as follows:

commisionProvider->subscribe(commissionListener);

Before logging out, unsubscribe the listener by using the unsubscribe method as follows:

commisionProvider->unsubscribe(commissionListener);

Public Methods

onChangeCommissionProviderStatus

Processes notifications about commission status changes.

onNeedUpdateCommissions

The method processes notifications about commission updating. The commissions must be recalculated.
