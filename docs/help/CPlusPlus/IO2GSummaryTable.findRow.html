public method IO2GSummaryTable.findRow

Brief

Finds a row in the IO2GSummaryTable by an OfferID.

Declaration
C++
virtual bool  findRow (const char * id, IO2GSummaryTableRow *& row) = 0

Parameters
id

The unique identifier of a traded instrument.
row

[out] The row fetched.

Details

If the row is not found, the method returns false.

Example

Find summary by OfferID [show]

Find summary by OfferID [hide]

    O2G2Ptr<IO2GSummaryTable> summaryTable = (IO2GSummaryTable *)tableManager->getTable(Summary);
    O2GSummaryTableRow summary = NULL;
    if (summaryTable->findRow(mOfferID.c_str(), summary))
    {
        std::cout << "OfferID: " << summary->getOfferID() <<
                     " NetPL = " << summary->getNetPL() <<
                     " Amount = " << summary->getAmount() << std::endl;
        summary->release();
    }

Note: The returned row contains the current values of fields. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. One can use the returned row in different threads without synchronization.
