public method IO2GOffersTable.getNextRowByMultiColumnValues

Brief

Gets the next row from IO2GOffersTable based on the multiple columns values.

Declaration
C++
virtual bool  getNextRowByMultiColumnValues (const int columnCount, const char *columnNames[], O2GRelationalOperators conditions[], const void *columnValues[], IO2GTableIterator &iterator, IO2GOfferTableRow *&row) = 0

Parameters
columnCount

Number of columns in which the search is to be performed.
columnNames

The array of column names in the Offers table.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the column specified by the columnNames parameter. For example, if you want to search the Offers table for tradable Forex instruments only, the columnNames parameter value is an array of InstrumentType and TradingStatus, the columnValues parameter is an array of 1 and O, columnCount parameter value is 2.
iterator

The table iterator.
row

[out] The row fetched.

Details

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all except between conditional statements for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo. For example, columnRelationals[] = {EqualTo, EqualTo, EqualTo}.

Example

Get tradable Forex instrument with certain pip size and contract currency from the Offers table. Which corresponds to SQL query SELECT rows FROM OffersTable WHERE IntrumentType = 1 AND PointSize >= 0.0001 AND ContractCurrency = "*S*". [show]

    O2G2Ptr<IO2GOffersTable> offersTable = (IO2GOffersTable *)tableManager->getTable(Offers);
 
    int instrumentType = 1;
    double pointSize = 0.0001;
    std::string contractCurrency = "*S*";
 
    bool found = false;
    IO2GTableIterator iterator;
    IO2GOfferTableRow *offer = NULL;
 
    const char *columnNames[] = {"InstrumentType", "PointSize", "ContractCurrency"};
    O2GRelationalOperators columnRelationals[] = {EqualTo, GreaterThanOrEqualTo, EqualTo};
    const void *columnValues[] = {(void *)&instrumentType, (void *)&pointSize, (void *)contractCurrency.c_str()};
 
    while (offersTable->getNextRowByMultiColumnValues(3, columnNames, columnRelationals, columnValues, iterator, pOffer))
    {
        found = true;
        std::cout << "Instrument: " << offer->getInstrument() <<
                     " Bid = " << offer->getBid() <<
                     " Ask = " << offer->getAsk() <<
                     " PipCost = " << offer->getPipCost() << std::endl;
        offer->release();
    }
    if (!found)
        std::cout << "No matching offers found" << std::endl;

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
