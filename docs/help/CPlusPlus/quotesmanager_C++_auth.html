Using Quotes Manager API with Trading Connection

Brief

The article discusses how to use Quotes Manager API with an established trading connection.

Details

ForexConnect SDK version 1.6 includes the updated versions of all three APIs: ForexConnect API, Price History API, and Quotes Manager API.

ForexConnect version 1.6 requires Quotes Manager API to have an established trading connection. The QuotesManagerFactory class of Quotes Manager API will not be available anymore. You will need to use the IPriceHistoryCommunicator interface of Price History API to get an instance of the IQuotesManager class.

Please note that the price history received from Quotes Manager API with an established trading connection will be account-specific, so it may differ slightly from the generic prices you used to receive without the trading connection (due to different price streams and price adjustments).

To keep your application working after ForexConnect version 1.6 is installed, do the following:

  1. For Win32/Win64:
    Add ForexConnect.lib, pricehistorymgr.lib, quotesmgr2.lib as additional dependencies for the linker input. See Including Quotes Manager API on Win32/Win64 for details.

    For Linux/MacOS:
    Add libForexConnect and libpricehistorymgr to the list of libraries in the linker options. See Including Quotes Manager API on Linux/MacOS for details.

  2. Change your code to get an instance of IQuotesManager by using the IPriceHistoryCommunicator interface:

    • Create a ForexConnect trading session. Subscribe the IO2GSessionStatus interface implementation to the status events.

    • Before logging in, create an instance of IPriceHistoryCommunicator by using PriceHistoryCommunicatorFactory::createCommunicator().

    • Log in to ForexConnect and wait until the communicator signals that it is ready (IPriceHistoryCommunicator::isReady()).

    • Get an instance of IQuotesManager by using IPriceHistoryCommunicator::getQuotesManager.

    • When you are done, log out, unsubscribe all listeners and release the instance of IPriceHistoryCommunicator.

    Example: [hide]

        // create the ForexConnect trading session
    O2G2Ptr<IO2GSession> session = CO2GTransport::createSession();
    O2G2Ptr<SessionStatusListener> statusListener = new SessionStatusListener(session, true,
        loginParams.getSessionID(),
        loginParams.getPin());
 
    // subscribe IO2GSessionStatus interface implementation for the status events
    session->subscribeSessionStatus(statusListener);
    statusListener->reset();
 
    // create an instance of IPriceHistoryCommunicator
    pricehistorymgr::IError *error = NULL;
    O2G2Ptr<pricehistorymgr::IPriceHistoryCommunicator> communicator(
        pricehistorymgr::PriceHistoryCommunicatorFactory::createCommunicator(session, "History", &error));
    O2G2Ptr<pricehistorymgr::IError> autoError(error);
 
    if (!communicator)
    {
        std::cout << error->getMessage() << std::endl;
        return;
    }
 
    // log in to ForexConnect
    session->login(loginParams.getLogin(), loginParams.getPassword(),
        loginParams.getURL(), loginParams.getConnection());
 
    if (statusListener->waitEvents() & statusListener->isConnected())
    {
        O2G2Ptr<CommunicatorStatusListener> communicatorStatusListener(new CommunicatorStatusListener());
        communicator->addStatusListener(communicatorStatusListener);
 
        // wait until the communicator signals that it is ready
        if (communicator->isReady() ||
            communicatorStatusListener->waitEvents() & communicatorStatusListener->isReady())
        {
            O2G2Ptr<quotesmgr::IQuotesManager> quotesManager(communicator->getQuotesManager());
            //TODO: All QuotesManager logic.
        }
        communicator->removeStatusListener(communicatorStatusListener);
 
        statusListener->reset();
        session->logout();
        statusListener->waitEvents();
    }
    session->unsubscribeSessionStatus(statusListener);

The Instance of IQuotesManager that you get by using the IPriceHistoryCommunicator interface will have following default parameters:

Parameter

Default value

Host name

The name of the Quotes Manager server.

TCP port

The TCP port of the Quotes Manager server.

Trading day offset

-7 hours (see CandlePeriod::getCandle for details).

Trading week offset

0 days (see CandlePeriod::getCandle for details).

To set the path where Quotes Manager API must store its cached data, use the quotesManagerDataPath parameter of the PriceHistoryCommunicatorFactory::createCommunicator method of Price History API.

To set proxy settings, use the PriceHistoryCommunicatorFactory::setProxy method of Price History API.
