interface IPriceHistoryCommunicatorListener

Parents
IAddRef

Brief

The interface to the Price History API communicator request result listener.

Details

The user application must implement this interface and then attach the implementation using the IPriceHistoryCommunicator::addListener() in order to be notified when the price request execution is finished.

Please note that the notification may be called from a different thread than the thread that was used to send the request.

The type defined in the pricehistorymgr library. The namespace is pricehistorymgr.

Public Methods

onRequestCancelled

The method is called when the request execution is canceled by the user application.

onRequestCompleted

The method is called when the request execution has been successfully completed.

onRequestFailed

The method is called when the request execution cannot be completed successfully.
