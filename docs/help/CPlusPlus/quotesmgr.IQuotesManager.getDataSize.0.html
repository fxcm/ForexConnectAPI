public method IQuotesManager::getDataSize

Brief

Gets the amount of data used by the cache for the specified instrument, base timeframe and year.

Declaration
C++
virtual int64  getDataSize (const char *instrument, const char *timeframe, int year, IError **error = 0) = 0

Parameters
instrument

The name of the instrument.
timeframe

The name of the base timeframe.

See How does Quotes Manager Work (Business Logic)? for an explanation of what the base timeframe is. Use getBaseTimeframes() to get the list of base timeframes.
year

The year (e.g. 1998 or 2005).

To get the list of instruments and the range of dates where the price data is available, use the getInstruments() method.
error

[output] If not NULL and an error occurred it will contain a pointer to a detailed error description object. It must be released by a caller after the use.
