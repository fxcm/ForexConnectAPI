public method IO2GTradesTable.getNextRowByCondition

Brief

Gets the next row from IO2GTradesTable based on any of the condition.

Declaration
C++
virtual bool  getNextRowByCondition (const char *columnName, O2GRelationalOperators condition, const void *columnValues[], IO2GTableIterator &iterator, IO2GTradeTableRow *&row) = 0

Parameters
columnName

The name of a column in the Trades table.
condition

The relation which should be met for table values.
columnValues

The array of values of the column specified by the columnName parameter. For example, if you want to search Trades table for positions which were made during the last hour, columnName parameter value is Time and the columnValues parameter is an array of two dates (the lower and the upper values) you want to search between.
iterator

The table iterator.
row

[out] The row fetched.

Details

This method allows finding all rows that correspond to the specified condition.
The method gets value for searching from columnValues[0] for all O2GRelationalOperators. For Between operator the method uses both columnValues[0] and columnValues[1]. columnValues[0] is used as the lower value and columnValues[1] is used as upper value.

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all relational operators including Between for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo.

    O2G2Ptr<IO2GTradesTable> tradesTable = (IO2GTradesTable *)tableManager->getTable(Trades);
 
    std::string accountID = "12345";
    std::string offerID = "1";
    double grossPL = 0;
 
    bool found = false;
    IO2GTableIterator iterator;
    IO2GTradeTableRow *trade = NULL;
 
    const char *columnNames[] = {"AccountID", "OfferID", "GrossPL"};
    O2GRelationalOperators columnRelationals[] = {EqualTo, EqualTo, GreaterThan};
    const void *columnValues[] = {(void *)accountID.c_str(), (void *)offerID.c_str(), (void *)&grossPL};
 
    while (tradesTable->getNextRowByColumnValues(3, columnNames, columnRelationals, columnValues, iterator, trade))
    {
        found = true;
        std::cout << "TradeID: " << trade->getTradeID() <<
                     " OfferID = " << trade->getOfferID() <<
                     " Amount = " << trade->getAmount() << std::endl;
        trade->release();
    }
    if (!found)
        std::cout << "No matching trades found." << std::endl;

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
