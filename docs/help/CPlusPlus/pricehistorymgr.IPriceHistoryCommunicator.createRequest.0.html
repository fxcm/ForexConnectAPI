public method IPriceHistoryCommunicator::createRequest

Brief

Creates a new price history request.

Declaration
C++
virtual IPriceHistoryCommunicatorRequest*  createRequest (const char *instrument, IO2GTimeframe *timeframe, DATE from, DATE to, int quotesCount, IError **error) = 0

Parameters
instrument

The instrument name. The instrument must be one of the instruments the ForexConnect session is subscribed to.

To check the list of the instruments, use the offers table. The name of the instrument is kept in Instrument column of the table.
timeframe

The timeframe of the history.

To get the list of standard supported timeframes, get an instance of IO2GTimeframeCollection. Or you can use a custom timeframe that can be created using ITimeframeFactory.
from

Date/time of the oldest bar/tick in the history.

Use 0 in order to get quotesCount bars ending at to date/time.

The date/time must be in the UTC time zone.
to

Date/time of the most recent bar/tick in the history.

Use 0 to get the collection up to the most recent ("now") bar/tick.

The date/time must be in the UTC time zone.
quotesCount

The maximum number of bars in the history.

Use -1 to get all bars between from and to date. In case -1 is used, the from date must not be 0.
error

[output] If not NULL and an error occurred it will contain a pointer to a detailed error description object. It must be released by a caller after the use.

Returns

The object returned must be released after usage by a caller. It may be released just after sending if it's not required anymore. If an error occurred returns NULL.

Details

The method only creates the request but does not send it. Use sendRequest() to send the request to the server.

Example: Creating a 1-minute historical request for yesterday (for Win32). [hide]

#include "ForexConnect.h"
#include "pricehistorymgr/pricehistorymgr.h"
 
using namespace pricehistorymgr;
 
class MyClass
{
    ...
    IO2GSession *mTradingSession;
    IPriceHistoryCommunicator *mPriceHistoryCommunicator;
 
    ...
    void myMethod()
    {
        IO2GRequestFactory *factory = mTradingSession->getRequestFactory();
        // will be NULL if you are not logged in
        if (!factory)
        {
            //process error
            return;
        }
        IO2GTimeframeCollection *timeframes = factory->getTimeFrameCollection();
        IO2GTimeframe *timeframe = timeframes->get("m1");
 
        SYSTEMTIME to;
        GetSystemTime(&to);
        to.wHour = 0;
        to.wMinute = 0;
        to.wSecond = 0;
        to.wMilliseconds = 0;
 
        SYSTEMTIME from(to);
        from.wDay -= 1;
 
        DATE fromDate, toDate;
        SystemTimeToVariantTime(&from, &fromDate);
        SystemTimeToVariantTime(&to, &toDate);
 
        const char *instrument = "EUR/USD";
 
        IError *error = NULL;
        IPriceHistoryCommunicatorRequest *request =
            mPriceHistoryCommunicator->createRequest(instrument, timeframe, fromDate, toDate, -1, &error);
 
        if (request == NULL)
        {
            if (error != NULL)
            {
                //process error
                //...
                error->release();
            }
        }
        else
        {
            mPriceHistoryCommunicator->sendRequest(request, &error);
 
            if (error != NULL)
            {
                //process error
                //...
                error->release();
            }
            request->release();
        }
 
        timeframe->release();
        timeframes->release();
        factory->release();
    }
};
