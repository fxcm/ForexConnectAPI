public method IO2GAccountsTable.getNextRowByCondition

Brief

Gets the next row from IO2GAccountsTable based on any of the condition.

Declaration
C++
virtual bool  getNextRowByCondition (const char *columnName, O2GRelationalOperators condition, const void *columnValues[], IO2GTableIterator &iterator, IO2GAccountTableRow *&row) = 0

Parameters
columnName

The name of a column in the Accounts table. For example, AccountKind.
condition

The relation which should be met for table values.
columnValues

The array of values of the column specified by the columnName parameter. For example, if you want to search the Accounts table for positions with amount of accounting which is between 10000 and 20000. the columnName parameter value is Equity and the columnValues parameter is an array of two amounts (the lower and the upper values) you want to search between.
iterator

The table iterator.
row

[out] The row fetched.

Details

This method allows finding all rows that correspond to the specified condition.
The method gets value for searching from columnValues[0] for all O2GRelationalOperators. For Between operator the method uses both columnValues[0] and columnValues[1]. columnValues[0] is used as the lower value and columnValues[1] is used as upper value.

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all relational operators including Between for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo.

Example

Get trading accounts or manager accounts from the Accounts table [show]

Get trading accounts or manager accounts from the Accounts table [hide]

    O2G2Ptr<IO2GAccountsTable> accountsTable = (IO2GAccountsTable *)tableManager->getTable(Accounts);
    bool found = false;
    IO2GTableIterator iterator;
    IO2GAccountTableRow *account = NULL;
    const void *columnValues[] = {(void *)"32", (void *)"36"};
    while(accountsTable->getNextRowByColumnValues("AccountKind", 2, columnValues, iterator, account))
    {
        found = true;
        std::cout << "AccountID: " << account->getAccountID() <<
                     " Equity = " << account->getEquity() <<
                     " UsableMargin = " << account->getUsableMargin() << std::endl;
        account->release();
    }
    if (!found)
        std::cout << "No accounts found." << std::endl;

Note: The returned row contains the current column values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
