static public method CO2GTransport::setNumberOfReconnections

Brief

Sets the number of attempts to reconnect.

Declaration
C++
static void  setNumberOfReconnections (const int Number)

Parameters
Number

The number of attempts to reconnect. To set an infinite number of attempts, use the value INFINITE_NUMBER_OF_RECONNECTIONS. This parameter will be used during the next call of the IO2GSession.login method.
If the value is equal to 0, the system will not attempt to reconnect.

Please see article Session Statuses for details.
