public method IO2GClosedTradesTable.getNextRowByMultiColumnValues

Brief

Gets the next row from IO2GClosedTradesTable based on the multiple columns values.

Declaration
C++
virtual bool  getNextRowByMultiColumnValues (const int columnCount, const char *columnNames[], O2GRelationalOperators conditions[], const void *columnValues[], IO2GTableIterator &iterator, IO2GClosedTradeTableRow *&row) = 0

Parameters
columnCount

Number of columns in which the search is to be performed.
columnNames

The array of column names in the Closed Trades table.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the column specified by the columnNames parameter. For example, if you want to search the ClosedTrades table for positions by AccountID 12345 and EUR/USD instrument only, the columnNames parameter value is an array of AccountID and OfferID, the columnValues parameter is an array of 12345 and 1, the columnCount parameter value is 2.
iterator

The table iterator.
row

[out] The row fetched.

Details

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all except between relational operators for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo. For example, columnRelationals[] = {EqualTo, EqualTo, EqualTo}.

Example

Get closed positions by specified AccountID and OfferID where grossPL equals 0 from the ClosedTrades table. Which corresponds to SQL query SELECT rows FROM ClosedTradesTable WHERE AccountID = "12345" AND OfferID = "1" AND GrossPL > 0 . [show]

    O2G2Ptr<IO2GClosedTradesTable> closedTradesTable = (IO2GClosedTradesTable *)tableManager->getTable(ClosedTrades);
 
    std::string accountID = "12345";
    std::string offerID = "1";
    double grossPL = 0;
 
    bool found = false;
    IO2GTableIterator iterator;
    IO2GClosedTradeTableRow *closedTrade = NULL;
 
    const char *columnNames[] = {"AccountID", "OfferID", "GrossPL"};
    O2GRelationalOperators columnRelationals[] = {EqualTo, EqualTo, GreaterThan};
    const void *columnValues[] = {(void *)accountID.c_str(), (void *)offerID.c_str(), (void *)&grossPL};
 
    while (closedTradesTable->getNextRowByMultiColumnValues(3, columnNames, columnRelationals, columnValues, iterator, closedTrade))
    {
        found = true;
        std::cout << "TradeID: " << closedTrade->getTradeID() <<
                     " OfferID = " << closedTrade->getOfferID() <<
                     " Amount = " << closedTrade->getAmount() << std::endl;
        closedTrade->release();
    }
    if (!found)
        std::cout << "No matching closed positions found." << std::endl;

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
