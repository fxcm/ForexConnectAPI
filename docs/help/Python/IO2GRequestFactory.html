class O2GRequestFactory

Brief

A request factory.

Details

A request factory is used to create and fill parameters for all server requests.

To get an instance of the request factory, use the O2GSession.request_factory method.

The module is forexconnect.fxcorepy

Public Properties

last_error

Gets information about the error (for example, when incorrect request parameters are specified).

timeframe_collection

Gets the collection of timeframes which can be used for the market data snapshot request.

Public Methods

create_order_request

Generates a request for creation of an order.

create_refresh_table_request

Creates a request to get the latest snapshot of the specified table.

create_refresh_table_request_by_account

Creates a request for a table containing data about one account.

create_value_map

Creates a value map.
