account_activity Table

Brief

The article describes the Account Activity table of the report.

Details

The Account Activity table contains information about all transactions that were posted to the account during the report statement period. The identifier of the table is account_activity.

The table has data rows and a total row. One data row contains information about one transaction. The total row contains summarized information about all transactions. Data rows can be distinguished from a total row by the value of the grouping_type column. If the value is 2, the row is a data row. If the value is 3, the row is a total row. Note that though a total row includes information for all columns of the table, only the amount of posted transactions (amount) is relevant and makes sense.

All data rows are arranged in ascending order by the date and time (time_posted) when the transaction was posted to the account.

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

grouping_type

INTEGER

Defines whether the row is a data row or a total row.
The value 2 indicates a data row, the value 3 indicates a total row.

time_posted

DATE

The date and time when the transaction was posted. The date and time has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

The value makes sense only for data rows.

type_id

INTEGER

The unique identification number of the transaction type (see the table below).
The value makes sense only for data rows.

code

STRING

The short (or abbreviated) localized code of the transaction type (see the table below).
The value makes sense only for data rows.

description

STRING

The default localized description of the transaction type (see the table below).
The value makes sense only for data rows.

The default description may be accompanied by additional notes provided by the operator who performed the transaction.

account

STRING

The identifier of the account (as it is displayed in the Trading Station) the report was requested for.
The value makes sense only for data rows.

ticket_id

INTEGER

The unique identification number of the position the transaction is associated with. If the transaction is not associated with any positions, the cell has an empty value.
The value makes sense only for data rows.

amount

DOUBLE

The amount of the transaction.

The value can be either positive or negative. A positive value indicates that the amount was credited, a negative value indicates that the amount was debited.
The value makes sense for data rows as well as for a total row.

The amount is expressed in the account denomination currency.

balance

DOUBLE

The amount of funds in the account after the transaction was posted. The balance does not reflect floating (unrealized) profit/loss.
The value makes sense only for data rows.

The balance is expressed in the account denomination currency.
