Report Description

Brief

The section describes the report as it appears in the XML format.

Details

The report content that is common to CAS reports for all kinds of accounts is described in the articles Report Request Parameters, Report Constants, account_info_office Table, account_info_user Table, and account_info_parameters Table.

The sections Self-Traded, LAMM Accounts, Funds Manager (PAMM) Account, and Managed (PAMM) Account describe the report content that is specific to certain account kinds.

Articles

Report Request Parameters

The article describes the request parameters of the report.

Report Constants

The article describes the constants of the report.

account_info_office Table

The article describes the report table containing broker information.

account_info_user Table

The article describes the report table containing information about the account owner.

account_info_parameters Table

The article describes the report table containing account information.

Groups

Self-Traded, LAMM Accounts

The section describes all report tables associated with self-traded (Trade) and funds manager/managed (LAMM) accounts.

Funds Manager (PAMM) Account

The section describes all report tables associated with funds manager (PAMM) accounts.

Managed (PAMM) Account

The section describes all report report tables associated with managed (PAMM) accounts.
