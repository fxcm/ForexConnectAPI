class O2GResponse

Brief

The class contains a response received from the trading server.

Details

There are two types of responses:

  • Responses provided by the server as an answer to a user request

  • Responses provided by the server as a result of trading tables updates

The way a response object is processed depends on the response type.

Processing user request responses

Notifications about a request answer are received by an instance of the ResponseListener class (implementing the AO2GResponseListener abstract class) specified in the request.

Requests may be successfully completed or may fail.

When ResponseListener receives a notification about a completed or failed request, it calls the appropriate method: ResponseListener.on_request_completed or ResponseListener.on_request_failed.

The type of a response depends on the request type. To find out the type of your response, use the O2GResponse.type property.

To process the contents of a response object, you must use a reader created by using the method O2GResponseReaderFactory.create_reader.
For the list of the response types and their appropriate readers (or a value for the MARGIN_REQUIREMENTS_RESPONSE response type) returned by the method, see the following table.

Processing table updates responses

In order to receive notifications about updates of a certain table, you must request the information about the table first. After successful completion of the initial request, responses of the TABLES_UPDATES type are sent automatically each time the table data are changed on the server.

For example, if you want to receive open positions updates, you must first send a request to get the initial open position information.

request = request_factory.create_refresh_table_request(O2GTableType.TRADES)

After successful completion of this request, you receive all updates of the Trades table automatically.

Notifications about table updates are received by an instance of the ResponseListener class (implementing the AO2GResponseListener abstract class) specified in the request.

When ResponseListener receives a notification about a table update, it calls the method ResponseListener.on_tables_updates.

To process the contents of a response object, you must use a reader created by using the method O2GResponseReaderFactory.create_reader.

Note: If your application uses O2GTableManager, processing of table updates is done in methods of the TableListener class (implemening the AO2GTableListener abstract class).
