public method ForexConnect.login_with_token

Brief

Creates a second trading session and starts the connection with the specified trade server using a token.

Declaration
Python
login_with_token((str)user_id, (str)token, (str)url = http://fxcorporate.com/Hosts.jsp, (str)connection = Demo, (str)session_id = None, (str)pin = None, (typing.Callable[[O2GSession, AO2GSessionStatus.O2GSessionStatus], None])session_status_callback = None, (bool)use_table_manager = True, (typing.Callable[[O2GTableStatus, O2GTableManager], None])table_manager_callback = None) -> O2GSession

Parameters
user_id

The user name.
token

The token.
url

The URL of the server. The URL must be a full URL, including the path to the host descriptor. The default value of the parameter is http://fxcorporate.com/Hosts.jsp.
connection

The name of the connection, for example Demo or Real. The default value of the parameter is Demo.
session_id

The database name. Required only for users who have accounts in more than one database. The default value of the parameter is None.
pin

The PIN code. Required only for users who have PIN codes. The default value of the parameter is None.
session_status_callback

The function that is called when the session status changes. The default value of the parameter is None.
use_table_manager

Defines whether ForexConnect is started with the table manager. The default value of the parameter is True.
table_manager_callback

The function that is called when the table manager status changes. The default value of the parameter is None

Details

Returns an instance of O2GSession or raises an exception LoginFailedError in case of an error.
