Self-Traded, LAMM Accounts

Brief

The section describes all report tables associated with self-traded (Trade) and funds manager/managed (LAMM) accounts.

Details

Diagram [show]

Diagram [hide]

Note that a set of tables in the report depends on the trading mode (position maintenance) of the account. For details, see the following examples.

The structure of the report for the account with the One Side, Both Sides, or FIFO trading mode: [show]

The structure of the report for the account with the One Side, Both Sides, or FIFO trading mode: [hide]

<rdf:report xmlns:rdf="http://re.fxcm.com/2008/2.0/format-xml">
    <rdf:parameters>
        ...report request parameters...
    </rdf:parameters>
    <rdf:data connection="100KREAL">
        <rdf:constants>
            ...report constants...
        </rdf:constants>
        <rdf:table name="account_info_office">
            ...report table...
        </rdf:table>
        <rdf:table name="account_info_user">
            ...report table...
        </rdf:table>
        <rdf:table name="account_info_parameters">
            ...report table...
        </rdf:table>
        <rdf:table name="closed_trades" description="CLOSED TRADE LIST">
            ...report table...
        </rdf:table>
        <rdf:table name="orders" description="OUTSTANDING ORDERS">
            ...report table...
        </rdf:table>
        <rdf:table name="open_floating_positions" description="OPEN/FLOATING POSITIONS">
            ...report table...
        </rdf:table>
        <rdf:table name="account_activity" description="ACCOUNT ACTIVITY">
            ...report table...
        </rdf:table>
        <rdf:table name="account_summary" description="ACCOUNT SUMMARY">
            ...report table...
        </rdf:table>
    </rdf:data>
</rdf:report>
