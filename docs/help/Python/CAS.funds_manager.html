Funds Manager (PAMM) Account

Brief

The section describes all report tables associated with funds manager (PAMM) accounts.

Details

Diagram [show]

Diagram [hide]

Note that a set of tables in the report depends on the trading mode (position maintenance) of the account. For details, see the following examples.

The structure of the report for the account with the One Side, Both Sides, or FIFO trading mode: [hide]

        ...report request parameters...
    </rdf:parameters>
    <rdf:data connection="100KREAL">
        <rdf:constants>
            ...report constants...
        </rdf:constants>
        <rdf:table name="account_info_office">
            ...report table...
        </rdf:table>
        <rdf:table name="account_info_user">

        <rdf:table name="account_info_parameters">

        <rdf:table name="closed_trades" description="CLOSED TRADE LIST">

        </rdf:table>

            ...report table...
        </rdf:table>
        <rdf:table name="orders" description="OUTSTANDING ORDERS">
