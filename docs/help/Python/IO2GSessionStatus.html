class AO2GSessionStatus

Brief

The abstract class provides the method signatures to process notifications about session status changes and login failure.

Details

The abstract class must be implemented by the application in order to process the status change of the session object.

When the user tries to log in, the session status changes to CONNECTING.
When the user tries to log in, the session status changes to CONNECTING.

If the login failed, the status changes to DISCONNECTED and the server returns an error message explaining why the login has failed. If you want to capture what went wrong, use the AO2GSessionStatus.on_login_failed method.

If the login was successful, the session status changes to CONNECTED. If you want to capture and process every status change of the session object, use the AO2GSessionStatus.on_session_status_changed method.

For a complete list of session statuses, please see AO2GSessionStatus.O2GSessionStatus. For detailed explanation of session statuses, please refer to the Session Statuses section.

If you want to use methods of the AO2GSessionStatus abstract class, you must create a class which implements the abstract class.

An instance of the class implementing the AO2GSessionStatus abstract class must be subscribed to the session object before calling the O2GSession.login method. It is accomplished by calling the O2GSession.subscribe_session_status method.

An instance of the class implementing the AO2GSessionStatus abstract class must be unsubscribed from the session object after calling the O2GSession.logout method. It is accomplished by calling the O2GSession.unsubscribe_session_status method.

The module is forexconnect.fxcorepy
