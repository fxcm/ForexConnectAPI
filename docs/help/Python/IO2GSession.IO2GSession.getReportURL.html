public method O2GSession.get_report_url

Brief

Gets a Combined Account Statement (CAS) report URL.

Declaration
Python
get_report_url((str)account_id, (datetime.datetime)date_from, (datetime.datetime)date_to, (str)format, (str)lang_id) -> str

Parameters
account_id

The unique identifier of the account the report is requested for.
date_from

The start date of the report statement period.

The specified date is used as the start date of the report period from the time the trading day begins, regardless of the specified time. The date/time must be in the UTC time zone.
date_to

The end date of the report statement period.

The specified date is used as the end date of the report period to the time the trading day ends, regardless of the specified time. The date/time must be in the UTC time zone.
format

The output format of the report.
Possible values:

HTML

HTML format

XML

XML format

PDF

Adobe PDF format

XLS

Microsoft Excel XML document format

The parameter is optional. The default value is HTML.
lang_id

The language and the locale of the report.
Possible values:

enu

English

jpn

Japanese

fra

French

esp

Spanish

cht

Chinese Traditional

chs

Chinese Simplified

rus

Russian

The parameter is optional. The default value is enu.

Details

The date and time in the report can be either in the UTC time zone or in the time zone of the server. See O2GSystemPropertiesReader for details. If the value of SERVER_TIME_UTC property is UTC, the date and time in the report will be in the UTC time zone. Otherwise, the date and time in the report will be in the time zone of the server. The time zone of the server can be checked in the BASE_TIME_ZONE property.
