public method ForexConnect.send_request

Brief

Sends a request and returns the appropriate response reader or a bool value.

Declaration
Python
send_request((O2GRequest)request, (ResponseListener)listener=None) -> typing.Any

Parameters
request

An instance of O2GRequest.
listener

An instance of ResponseListener. The default value of the parameter is None. If a listener is specified, it is also notified about receiving a response.

Details

The method sends a request, waits for a response, passes it to the method O2GResponseReaderFactory.create_reader, and returns an instance of the appropriate reader or a bool value.
In case of an error, the method raises RequestFailedError.
