static public method Common.create_table_listener

Brief

Creates a table listener.

Declaration
Python
create_table_listener((typing.Callable[[AO2GTableListener, str, O2GRow], None])on_add_callback = None, (typing.Callable[[AO2GTableListener, str, O2GRow], None])on_delete_callback = None, (typing.Callable[[AO2GTableListener, str, O2GRow], None])on_change_callback = None, (typing.Callable[[AO2GTableListener, O2GTableStatus], None])on_status_change_callback = None) -> TableListener

Parameters
on_add_callback

The function that is called when a row is added to the table. The function takes three arguments: an instance of the table listener that is being created, row_id (the row identifier for a specific trading table, the complete list of the identifiers is shown below), and an instance of O2GRow that has been added. The default value of the parameter is None.
on_delete_callback

The function that is called when a row is deleted from the table. The function takes three arguments: an instance of the table listener that is being created, row_id (the row identifier for a specific trading table, the complete list of the identifiers is shown below), and an instance of O2GRow that has been deleted. The default value of the parameter is None.
on_change_callback

The function that is called when a row in the table is changed. The function takes three arguments: an instance of the table listener that is being created, row_id (the row identifier for a specific trading table, the complete list of the identifiers is shown below), and an instance of O2GRow that has been changed. The default value of the parameter is None.
on_status_change_callback

The function that is called when the table status is changed. The function takes two arguments: an instance of the table listener that is being created and the table status (see O2GTableStatus). The default value of the parameter is None.
