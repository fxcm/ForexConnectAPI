public method ForexConnect.create_request

Brief

Creates a request.

Declaration
Python
create_request((typing.Dict[O2GRequestParamsEnum, str])params, (O2GRequestFactory)request_factory = None, (bool)root = True) -> O2GRequest

Parameters
params

The request parameters. See O2GRequestParamsEnum.
request_factory

An instance of O2GRequestFactory. The default value of the parameter is None, in this case an instance of the request factory of the current session is used.
root

Defines whether the request is root. The default value of the parameter is True.

Details

To send a request, use the method ForexConnect.send_request or ForexConnect.send_request_async.

If you use the method ForexConnect.send_request, the method returns the execution result or raises an exception RequestFailedError if an error occurs.

If you use the method ForexConnect.send_request_async, to get a request execution result, you need to specify a ResponseListener in the method.

The method uses the methods of O2GRequestFactory.

To create a request, use O2GRequestFactory.create_value_map and fill the result O2GValueMap with request parameters.
Then use O2GRequestFactory.create_order_request.
