class O2GRequest

Brief

A request to the server.

Details

The type is an indexable type.

Requests are sent to the server to perform operations, for example, create an order or close positions.
An appropriate response will be sent back for each request. A request and its response can be associated by the request identifier.

To create a request, use the one of the methods: ForexConnect.create_request, ForexConnect.create_order_request, Common.add_orders_into_group_request, Common.join_to_new_group_request, Common.close_trades_request.

The module is forexconnect.fxcorepy
