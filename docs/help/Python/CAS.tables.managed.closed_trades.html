closed_trades Table

Brief

The article describes the Closed Trade List table of the report.

Details

The Closed Trade List table contains information about all positions that were closed during the report statement period. The identifier of the table is closed_trades.

The table is available only if the account is set to a non-netting trading mode (the value of the position_maintenance costant is N, F or Y).

The table has data rows and a total row. One data row contains information about one closed position. The total row contains summarized information about all closed positions. Data rows can be distinguished from a total row by the value of the grouping_type column. If the value is 2, the row is a data row. If the value is 3, the row is a total row. Note that though a total row includes information for all columns of the table, only some of this information is relevant and makes sense, namely:

  • Gross profit/loss (gross_pl and statement_gross_pl)

  • Broker commission (comm and statement_comm)

  • Rollover interest (rollover and statement_rollover)

  • Profit/loss adjustment (adj and statement_adj)

  • Net profit/loss (net_pl)

All data rows are arranged in ascending order by the open date (open_date) of the position.

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

grouping_type

INTEGER

Defines whether the row is a data row or a total row.
The value 2 indicates a data row, the value 3 indicates a total row.

ticket_id

INTEGER

The unique identification number of the position.
The value makes sense only for data rows.

symbol

STRING

The instrument traded.
The value makes sense only for data rows.

open_rate

DOUBLE

The price the position was opened at.
The value makes sense only for data rows.

close_rate

DOUBLE

The price the position was closed at.
The value makes sense only for data rows.

open_date

DATE

The date and time when the position was opened. The open date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

The value makes sense only for data rows.

close_date

DATE

The date and time when the position was closed. The close date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

The value makes sense only for data rows.

gross_pl

DOUBLE

The amount of profit or loss realized during the entire lifetime of the position(s), i.e. from open_date to close_date. This amount excludes additional charges, such as broker commission (comm), rollover interest (rollover), and adjustment (adj).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The gross profit/loss is expressed in the account denomination currency.

markups

DOUBLE

The markups applied to the position.
The column is displayed if the report account is subject to MIFID II (Directive on Markets in Financial Instruments repealing Directive 2004/39/EC and the Regulation on Markets in Financial Instruments) requirements.

The value makes sense only for data rows.

The markups are expressed in pips.

comm

DOUBLE

The amount of broker commission charged during the entire lifetime of the position(s), i.e. from open_date to close_date.

The value can be either negative or zero. A negative value indicates that the commission was charged, a zero value indicates that the commission was not charged.
The value makes sense for data rows as well as for a total row.

The commission is expressed in the account denomination currency.

dividends

DOUBLE

Not used.

rollover

DOUBLE

The amount of rollover interest earned or paid during the entire lifetime of the position(s), i.e. from open_date to close_date.

The value can be either positive or negative. A positive value indicates that the rollover was earned, a negative value indicates that the rollover was paid.
The value makes sense for data rows as well as for a total row.

The rollover is expressed in the account denomination currency.

adj

DOUBLE

The amount of adjustment applied to the gross profit/loss (gross_pl) for the period from close_date of the position(s) to the current date and time.

The value can be either positive or negative. A positive value indicates that the gross profit/loss encreased, a negative value indicates that the gross profit/loss decreased.
The value makes sense for data rows as well as for a total row.

The adjustment is expressed in the account denomination currency.

net_pl

DOUBLE

The amount of profit or loss realized during the entire lifetime of the position(s), i.e. from open_date to close_date. This amount includes all charges, such as broker commission (comm), rollover interest (rollover), and adjustment (adj).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The net profit/loss is expressed in the account denomination currency.

statement_gross_pl

DOUBLE

The amount of profit or loss posted to the account during the report statement period. This amount excludes additional charges, such as broker commission (comm), rollover interest (rollover), and adjustment (adj).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The statement gross profit/loss is expressed in the account denomination currency.

statement_comm

DOUBLE

The amount of broker commission posted to the account during the report statement period. The statement commission may differ from the commission (comm) if, for example, the position(s) was(were) opened before the from date of the report statement period (see Combined Account Statement: Report Request Parameters).

The value can be either negative or zero. A negative value indicates that the commission was charged, a zero value indicates that the commission was not charged.
The value makes sense for data rows as well as for a total row.

The statement commission is expressed in the account denomination currency.

statement_dividends

DOUBLE

Not used.

statement_rollover

DOUBLE

The amount of rollover interest posted to the account during the report statement period. The statement rollover may differ from the rollover (rollover) if, for example, the position(s) was(were) opened before the from date of the report statement period (see Combined Account Statement: Report Request Parameters).

The value can be either positive or negative. A positive value indicates that the rollover was earned, a negative value indicates that the rollover was paid.
The value makes sense for data rows as well as for a total row.

The statement rollover is expressed in the account denomination currency.

statement_adj

DOUBLE

The amount of adjustment applied to the gross profit/loss (gross_pl) for the period from close_date of the position(s) to the till date of the report statement period (see Combined Account Statement: Report Request Parameters). The statement adjustment may differ from the adjustment (adj) if, for example, the gross profit/loss was adjusted after the till date of the report statement period.

The value can be either positive or negative. A positive value indicates that the gross profit/loss encreased, a negative value indicates that the gross profit/loss decreased.
The value makes sense for data rows as well as for a total row.

The statement adjustment is expressed in the account denomination currency.

buy_sell

STRING

The trade operation of the position.

The value B indicates that the position was opened by buying.
The value S indicates that the position was opened by selling.

The value makes sense only for data rows.
