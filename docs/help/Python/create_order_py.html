Creating Order

Brief

The article explains how to create an order.

Details

To create an order in your Python script, you must perform the following steps:

  1. Log in.

  2. Create a request for creating an order by calling the Forexconnect.create_order_request method. The set of order parameters depends on a particular order type. For order parameters description for each order type, see the article Order Request Parameters. For example:

        request = fx.create_order_request(
        order_type=fxcorepy.Constants.Orders.ENTRY,
        OFFER_ID="EUR/USD",
        ACCOUNT_ID="account_id",
        BUY_SELL=fxcorepy.Constants.BUY,
        AMOUNT=4000,
        RATE=1.1578,
    )

  3. When the order is created, it appears in the Orders table. To make sure that the order has been created, i.e. a new row with the corresponding order ID has been added to the table, you need to monitor Orders table updates.
    For this, define the on_add_callback callback function that will be called after you subscribe to the table updates, get the Orders table, create a table listener and subscribe it to the table updates.
    The callback function will be called in a separate thread. You can synchronize its results with your main thread by setting an event. In the following example, on_add_callback collects all rows added to the table and sets an event if an order row with the corresponding order ID is added.

     def on_added_order(self, _, __, order_row):
     order_id = order_row.order_id
     self.__orders[order_id] = order_row
     if self.__order_id == order_id:
     self.__event.set()
 
 ...
 
    orders_table = fx.get_table(ForexConnect.ORDERS)
    orders_listener = Common.subscribe_table_updates(orders_table, on_add_callback=on_added_order)

  4. Send the request for creating the order by calling the method ForexConnect.send_request and get the corresponding order ID from the response using the property O2GOrderResponseReader.order_id.

        try:
        resp = fx.send_request(request)
        order_id = resp.order_id
 
    except Exception as e:
        print("Exception: " + str(e))
        orders_listener.unsubscribe()
    ...

  5. Wait for the order to appear in the table. The order row might be added to the table before the response is received, so you need to check if an order row with the corresponding order ID has been already collected. For example:

     def wait(self, time, order_id):
     self.__order_id = order_id
 
     order_row = self.find_order(order_id)
     if order_row is not None:
         return order_row
 
     self.__event.wait(time)
 
     return self.find_order(order_id)
 
 def find_order(self, order_id):
     if order_id in self.__orders:
         return self.__orders[order_id]
     else:
         return None
 ...
 
         order_row = orders_monitor.wait(30, order_id)
         if order_row is None:
             print("Response waiting timeout expired.\n")
         else:
             print("The order has been added. OrderID={0:s}, "
                   "Type={1:s}, BuySell={2:s}, Rate={3:.5f}, TimeInForce={4:s}".format(
                 order_row.order_id, order_row.type, order_row.buy_sell, order_row.rate,
                 order_row.time_in_force))
             sleep(1)

  6. Unsubscribe the table listener from table updates. For example:

    orders_listener.unsubscribe()

  7. Log out.
