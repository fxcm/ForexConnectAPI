public method O2GOfferTableRow.is_instrument_type_valid

Brief

Gets the flag indicating whether the instrument_type field is valid or not.

Declaration
Python
is_instrument_type_valid() -> bool

Details

If the value is not valid (the flag is false), the corresponding field is not filled and returns the default value (an empty string for string, 0 for number and so on) and shall not be used. In this case, the value returned by the most recent command (table refresh or tables_updates), received for the offer table must be used instead.
