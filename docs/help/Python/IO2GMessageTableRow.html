class O2GMessageTableRow

Parents
O2GMessageRow

Brief

The class provides access to the message information.

Details

The class represents a single row of the Messages table.

If you want to track the Accounts table updates, you have to Subscribe for the table updates. See Getting trading table updates article for details.

The module is forexconnect.fxcorepy
