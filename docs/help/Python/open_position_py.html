Opening/Closing Position

Brief

The article explains how to open/close a position.

Details

Positions are opened and closed by orders. So, to open/close a position, you have to create an order. When the order is created, it appears in the Orders table. It stays in the table until it is executed. When the order is executed, a position is opened and appears in the Trades table or the position is closed and appears in the Closed Trades table.

Depending on the order type and the market conditions, the order execution may produce different results. The limited market liquidity may lead to failure to fill an order (order rejection) or to a partial fill of an order (only a part of the order is executed at the price). On the volatile market, the market price may significantly move away from the order price, which may also lead to order rejection for the Open Range and the Open Limit orders.

With different order types a trader has different time-in-force options that provide additional instructions on how long an order should remain active until it is executed or expires. For detailed description of orders, see the sections Order Types and Orders State Machines.

The following table summarizes all possible variants of the order execution and execution results:

Variant of order execution

Execution result

An opened position

A new position will appear in the Trades table. The position amount must be equal to the amount specified in the order request.

A closed position

A closed position will appear in the Closed Trades table. The position amount must not be less than the amount specified in the order request.

A partially opened/closed position

Either a new position will appear in the Trades table or a closed position will appear in the Closed Trades table. The position amount must be less than the amount specified in the order request.

A completely rejected order

A rejection message will appear in the Messages table. The order status will change to R in the Orders table.

A partially rejected order

Either a new position will appear in the Trades table or a closed position will appear in the Closed Trades table (depending on the account type).
A rejection message will appear in the Messages table.

To open or close a position in your Python script, you must perform the following steps:

  1. Log in.

  2. Create a request for creating an order by calling the Forexconnect.create_order_request method. The set of order parameters depends on a particular order type. For order parameters description for each order type, see the article Order Request Parameters. For example:

        request = fx.create_order_request(
        order_type=fxcorepy.Constants.TRUE_MARKET_OPEN,
        SYMBOL="EUR/USD",
        ACCOUNT_ID="account_id",
        BUY_SELL=fxcorepy.Constants.BUY,
        AMOUNT=4000,
    )

  3. Monitor Orders table updates.
    For this, define the on_add_callback, on_changed_callback, and on_deleted_callback callback functions that will be called after you subscribe to the table updates, get the Orders table, create a table listener and subscribe it to the table updates.
    The callback functions will be called in a separate thread. You can synchronize its results with your main thread by setting an event.

      def on_added_order(self, _, __, order_row):
      order_id = order_row.order_id
      self.__added_orders[order_id] = order_row
      if self.__order_id == order_id:
          self.__added_order_event.set()
 
  def on_changed_order(self, _, __, order_row):
      order_id = order_row.order_id
      self.__changed_orders[order_id] = order_row
      if self.__order_id == order_id:
          self.__changed_orders_event.set()
 
  def on_deleted_order(self, _, __, order_row):
      order_id = order_row.order_id
      self.__deleted_orders[order_id] = order_row
      if self.__order_id == order_id:
          self.__deleted_order_event.set()
 
      orders_table = fx.get_table(ForexConnect.ORDERS)
      orders_listener = Common.subscribe_table_updates(orders_table, on_add_callback=on_added_order,
                                                       on_delete_callback=on_deleted_order,
                                                       on_change_callback=on_changed_order)

  4. Monitor Trades table or Closed Trades table updates.
    For this, define the on_add_callback callback function that will be called after you subscribe to the table updates, get the Trades table or Closed Trades table, create a table listener and subscribe it to the table updates.
    The callback function will be called in a separate thread. You can synchronize its results with your main thread by setting an event.

      def on_added_trade(self, _, __, trade_row):
      open_order_id = trade_row.open_order_id
      self.__trades[open_order_id] = trade_row
      if self.__open_order_id == open_order_id:
          self.__event.set()
 
      orders_table = fx.get_table(ForexConnect.ORDERS)
      trades_listener = Common.subscribe_table_updates(trades_table, on_add_callback=on_added_trade)

  5. Send the request for creating the order by calling the method ForexConnect.send_request and get the corresponding order ID from the response using the property O2GOrderResponseReader.order_id.

          try:
          resp = fx.send_request(request)
          order_id = resp.order_id
 
      except Exception as e:
          print("Exception: " + str(e))
          trades_listener.unsubscribe()
          orders_listener.unsubscribe()
    ...

  6. Wait for the order to be added to the Orders table and executed and for a trade to appear in the Trades table or Closed Trades table. The order/trade row might be added to the table before the response is received, so you need to check if an order/trade row with the corresponding order ID has been already collected. For example:

      def wait_order(self, time, order_id):
      self.__order_id = order_id
 
      is_order_added = True
      is_order_changed = True
      is_order_deleted = True
 
      # looking for an added order
      if order_id not in self.__added_orders:
          is_order_added = self.__added_order_event.wait(time)
 
      if is_order_added:
          order_row = self.__added_orders[order_id]
          print("The order has been added. Order ID: {0:s}, Rate: {1:.5f}, Time In Force: {2:s}, Status: {3}".format(
              order_row.order_id, order_row.rate, order_row.time_in_force, order_row.status))
 
      # looking for a changed order
      if order_id not in self.__changed_orders:
          is_order_changed = self.__changed_orders_event.wait(time)
 
      if is_order_changed:
          order_row = self.__changed_orders[order_id]
          print("The order has been changed. Order ID: {0:s}, status {1}".format(order_row.order_id, order_row.status))
 
      # looking for a deleted order
      if order_id not in self.__deleted_orders:
          is_order_deleted = self.__deleted_order_event.wait(time)
 
      if is_order_deleted:
          order_row = self.__deleted_orders[order_id]
          print("The order has been deleted. Order ID: {0}, status {1}".format(order_row.order_id, order_row.status))
 
      return is_order_added and is_order_changed and is_order_deleted
 
  def wait_trade(self, time, open_order_id):
      self.__open_order_id = open_order_id
 
      trade_row = self.find_trade(open_order_id)
      if trade_row is not None:
          return trade_row
 
      self.__event.wait(time)
 
      return self.find_trade(open_order_id)
 
  def find_trade(self, open_order_id):
      if open_order_id in self.__trades:
          return self.__trades[open_order_id]
      return None
 
  ...
 
      else:
          # Waiting for an order to appear/to be deleted or timeout (default 30)
          is_success = wait_order(30, order_id)
 
          trade_row = None
          if is_success:
              # Waiting for a trade to appear or timeout (default 30)
              trade_row = wait_trade(30, order_id)
 
          if trade_row is None:
              print("Response waiting timeout expired.\n")
          else:
              print("For the order: OrderID = {0} the following positions have been opened:".format(order_id))
              print("Trade ID: {0:s}; Amount: {1:d}; Rate: {2:.5f}".format(trade_row.trade_id, trade_row.amount,
                                                                 trade_row.open_rate))
              sleep(1)

  7. Unsubscribe the table listeners from table updates. For example:

          orders_listener.unsubscribe()
      trades_listener.unsubscribe()

  8. Log out.
