open_floating_positions Table

Brief

The article describes the Open/Floating Positions table of the report.

Details

The Open/Floating Positions table contains information about all positions that remain open at the end (till) date of the report statement period (see Combined Account Statement: Report Request Parameters). The identifier of the table is open_floating_positions.

The table is available only if the account is set to a non-netting trading mode (the value of the position_maintenance costant is N, F or Y).

The table has data rows and a total row. One data row contains information about one open position. The total row contains summarized information about all open positions. Data rows can be distinguished from a total row by the value of the grouping_type column. If the value is 2, the row is a data row. If the value is 3, the row is a total row. Note that though a total row includes information for all columns of the table, only some of this information is relevant and makes sense, namely:

  • Floating profit/loss (floating_pl)

  • Broker commission (comm and statement_comm)

  • Rollover interest (rollover and statement_rollover)

  • Net profit/loss (net_pl)

All data rows are arranged in ascending order by the unique identification number (ticket_id) of the position.

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

grouping_type

INTEGER

Defines whether the row is a data row or a total row.
The value 2 indicates that a data row, the value 3 indicates a total row.

ticket_id

INTEGER

The unique identification number of the position.
The value makes sense only for data rows.

symbol

STRING

The instrument traded.
The value makes sense only for data rows.

open_date

DATE

The date and time when the position was opened. The open date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

The value makes sense only for data rows.

date

DATE

The end date of the report statement period.

If the end date is the current date (the report was requested "till now"), the value is the date and time when the report was requested.
If the end date is in the past, the value is the end of that trading day.
The value makes sense only for data rows.

rate

DOUBLE

The price the position was opened at.
The value makes sense only for data rows.

offer_rate

DOUBLE

The price of the instrument at the end date of the report statement period. This is the price the position can (or could) be closed at.

If the end date is the current date (the report was requested "till now"), the value is the current price of the instrument.
If the end date is in the past, the value is the price of the instrument at the end of that trading day.
The value makes sense only for data rows.

floating_pl

DOUBLE

The amount of floating (unrealized) profit or loss at the end date of the report statement period. This amount excludes additional charges, such as broker commission (comm) and rollover interest (rollover).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The floating profit/loss is expressed in the account denomination currency.

comm

DOUBLE

The amount of broker commission charged for the period from open_date of the position(s) to the end date of the report statement period.

The value can be either negative or zero. A negative value indicates that the commission was charged, a zero value indicates that the commission was not charged.
The value makes sense for data rows as well as for a total row.

The commission is expressed in the account denomination currency.

dividends

DOUBLE

Not used.

rollover

DOUBLE

The amount of rollover interest earned or paid for the period from open_date of the position(s) to the end date of the report statement period.

The value can be either positive or negative. A positive value indicates that the rollover was earned, a negative value indicates that the rollover was paid.
The value makes sense for data rows as well as for a total row.

The rollover is expressed in the account denomination currency.

net_pl

DOUBLE

The amount of floating (unrealized) profit or loss at the end date of the report statement period. This amount includes additional charges, such as broker commission (comm) and rollover interest (rollover).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The net profit/loss is expressed in the account denomination currency.

markups

DOUBLE

The markups applied to the position.
The column is displayed if the report account is subject to MIFID II (Directive on Markets in Financial Instruments repealing Directive 2004/39/EC and the Regulation on Markets in Financial Instruments) requirements.

The value makes sense only for data rows.

The markups are expressed in pips.

statement_comm

DOUBLE

The amount of broker commission posted to the account during the report statement period. The statement commission may differ from the commission (comm) if, for example, the position(s) was(were) opened before the from date of the report statement period (see Combined Account Statement: Report Request Parameters).

The value can be either negative or zero. A negative value indicates that the commission was charged, a zero value indicates that the commission was not charged.
The value makes sense for data rows as well as for a total row.

The statement commission is expressed in the account denomination currency.

statement_dividends

DOUBLE

Not used.

statement_rollover

DOUBLE

The amount of rollover interest posted to the account during the report statement period. The statement rollover may differ from the rollover (rollover) if, for example, the position(s) was(were) opened before the from date of the report statement period (see Combined Account Statement: Report Request Parameters).

Statement Rollover vs. Rollover: [show]

Statement Rollover vs. Rollover: [hide]

The value can be either positive or negative. A positive value indicates that the rollover was earned, a negative value indicates that the rollover was paid. The value makes sense for data rows as well as for a total row.

The statement rollover is expressed in the account denomination currency.

buy_sell

STRING

The trade operation of the position.

The value B indicates that the position was opened by buying.
The value S indicates that the position was opened by selling.

The value makes sense only for data rows.

precision

INTEGER

The precision (i.e. the number of digits after the decimal point) of the instrument price.
The value makes sense only for data rows.
