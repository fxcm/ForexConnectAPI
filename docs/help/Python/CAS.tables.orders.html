orders Table

Brief

The article describes the Outstanding Orders table of the report.

Details

The Outstanding Orders table contains information about all orders that remain unexecuted at the end (till) date of the report statement period (see Combined Account Statement: Report Request Parameters). The identifier of the table is orders.

All data rows are arranged in ascending order by the unique identification number (ticket_id) of the position to be opened or closed by the order.

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

order_id

INTEGER

The unique identification number of the order.

expire_date

DATE

The date and time when the order expires. The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

Makes sense only for orders with the DAY time-in-force option.

type

STRING

The type of the order. Possible values:

SE

Entry stop or OCO order

LE

Entry limit or OCO order

S

Stop order

ST

Trailing stop order

L

Limit order

O

Open market, open limit, open range or open order

C

Close market, close limit, close range or close order

MC

Margin call order

ticket_id

INTEGER

The unique identification number of the position to be opened or closed by the order.

symbol

STRING

The instrument to be bought/sold.

precision

INTEGER

The precision (i.e. the number of digits after the decimal point) of the instrument price.

volume

DOUBLE

The amount of the instrument to be bought/sold.

In case of FX instruments, the volume is expressed in the base currency of the instrument.
In case of CFD instruments, the volume is expressed in contracts.

date

DATE

The date and time when the order was created. The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

buy_sell

STRING

The trade operation of the order.

The value B indicates a buy order.
The value S indicates a sell order.

price

DOUBLE

The price specified in the order. In case of a peg order, the value is not populated.

peg_offset

DOUBLE

The distance between the order price and the primary order price. The value is populated if the order is a peg order.
If a peg order is activated or executed at the moment the report is requested, the value is not populated.

The value can be either positive or negative.

The distance is expressed in pips.

market_price

DOUBLE

The price of the instrument at the end date of the report statement period.

The value is a sell price if the trade operation of the order (buy_sell) is sell (S).
The value is a buy price if the trade operation of the order (buy_sell) is buy (B).

If the end date is the current date (the report was requested "till now"), the value is the current price of the instrument.
If the end date is in the past, the value is the price of the instrument at the end of that trading day.

created_by

STRING

The name (login) of the user who placed the order.
