scheduled_activity Table

Brief

The article describes the Scheduled Activity table of the report.

Details

The Scheduled Activity table contains information about all transactions (such as, for example, deposit, withdrawal, or transfer) to be posted to all associated managed accounts at the end of the trading day. Each transaction is represented as a scheduled task. Once a task is executed, the transaction is posted to the accounts. The identifier of the table is scheduled_activity.

Note that the table is available only if the report is requested "till now" and if information about scheduled tasks is found.

The table has data rows and a total row. One data row contains information about one task. The total row contains summarized information about all tasks. Data rows can be distinguished from a total row by the value of the grouping_type column. If the value is 2, the row is a data row. If the value is 3, the row is a total row. Note that though a total row includes information for all columns of the table, only the amount of scheduled transactions (amount) is relevant and makes sense.

All data rows are arranged in ascending order by the date and time of the scheduled task execution (execute_date).

Column identifier

Column data type

Description

grouping_type

INTEGER

Defines whether the row is a data row or a total row.
The value 2 indicates a data row, the value 3 indicates a total row.

delay

STRING

Defines whether the task execution is delayed or not. Possible values:

N

The task is scheduled on time, i.e. will be executed at the end of the current trading day.

Y

The task is delayed.

The value makes sense only for data rows.

description

STRING

The description of the task (see the table below).
The value makes sense only for data rows.

execute_date

DATE

The date and time when the task is to be executed. The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

The value makes sense only for data rows.

schedule_type_id

INTEGER

The unique identification number of the task type (see the table below).
The value makes sense only for data rows.

type_id

INTEGER

The unique identification number of the transaction type (see the table below). For a complete list of transaction types, see Transaction Types in account_activity Table.
The value makes sense only for data rows.

code

STRING

The short (or abbreviated) localized code of the task type (see the table below).
The value makes sense only for data rows.

amount

DOUBLE

The amount of the transaction(s) to be posted to the managed accounts.

The value can be either positive or negative. A positive value indicates that the amount will be credited, a negative value indicates that the amount will be debited.
The value makes sense for data rows as well as for a total row.

The amount is expressed in the account denomination currency.
