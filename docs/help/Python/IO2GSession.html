class O2GSession

Brief

A session object.

Details

A session is an object which can be connected to the trade server. Only one connection can be established from one session object, but multiple connections can be created at the same time.

Use the ForexConnect.login/ForexConnect.login_with_token method or the O2GTransport.create_session method to get a session instance.

The module is forexconnect.fxcorepy
