Report Constants

Brief

The article describes the constants of the report.

Details

Constant name

Constant type

Description

user_name

STRING

The name of the user who requested the report.

base_currency

STRING

The denomination currency of the account the report is requested for.

precision

INTEGER

The precision (i.e. the number of digits after the decimal point) of the account denomination currency.

account_kind

INTEGER

The kind of the account the report is requested for. Possible values:

32

Self-traded account, funds manager account (only LAMM), managed account (only LAMM)

36

Funds manager account (only PAMM)

38

Managed account (only PAMM)

position_maintenance

STRING

The trading mode of the account. Possible values:

N

One Side - the trading mode that prohibits hedging and may require compliance with the NFA FIFO rule.

F

FIFO - the trading mode that prohibits hedging and requires compliance with the NFA FIFO rule.

Y

Both Sides - the trading mode that allows hedging and does not require compliance with the NFA FIFO rule.

0

Netting Only - the trading mode where at any time there is only one aggregate position (net position) per instrument. Each net position reflects the amount of the instrument bought or sold that has not yet been offset by opposite transactions.

D

Day Netting - the trading mode where there is only one aggregate position (net position) per instrument for the current trading day. Each net position reflects the amount of the instrument bought or sold that has not yet been offset by opposite transactions. All net positions that are not offset within the same trading day are disabled at the end of the day and automatically closed at their value (settlement) dates.

swap_flag

STRING

Indicates whether the account is a Day Netting Swap account. Possible values:

Y

The account is a Day Netting Swap account.

N

The account is not a Day Netting Swap account.
