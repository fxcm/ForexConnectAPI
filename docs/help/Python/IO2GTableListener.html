class AO2GTableListener

Brief

The abstract class provides method signatures to process notifications about trading tables events: adding/updating/deleting of rows, and changes in a table status.

Details

After the successful login, you must obtain an instance of the O2GTableManager class.

The table manager keeps in memory the trading tables and therefore allows access to the up-to-date field values and ability to capture table events.

If you want to process notifications about specific table events, you must obtain an instance of the class derived from the O2GTable class.

Limitations

The AO2GTableListener is notified only about the trading tables updates (see O2GResponseType.TABLE_UPDATES).
Note: In order to process the response which comes as an answer to a request execution, you application needs to implement the AO2GResponseListener abstract class.

Implementation

If you want to use methods of the AO2GTableListener abstract class, you must create a class that implements the abstract class.

In your application you must create an instance of the class that implements the abstract class.

This instance must be subscribed to a table object event.
You must subscribe to each event individually by using different methods of the O2GTable class. For example, if you want to process notifications about updates of the Trades table, call the O2GTable.subscribe_update method.

Before the logout, you must unsubscribe the listener from the table object.

The module is forexconnect.fxcorepy

Public Methods

on_added

Processes a notification about the row addition to a table.

on_changed

Processes a notification about the row change in a table.

on_deleted

Processes a notification about the row deletion from a table.

on_status_changed

Processes notifications about a table status changes.
