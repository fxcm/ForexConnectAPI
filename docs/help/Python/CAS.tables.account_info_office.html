account_info_office Table

Brief

The article describes the report table containing broker information.

Details

The table contains information about the broker that opened the report account. The table identifier is account_info_office.

Column identifier

Column data type

Description

office_name

STRING

The full name of the broker, for example, Forex Capital Markets LLC.

office_shortname

STRING

The short name of the broker, for example, FXCM.

office_address

STRING

The address of the broker in the format Address1, Address2 City, State Zip code Country.
