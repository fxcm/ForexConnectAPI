public method ForexConnect.get_table_reader

Brief

Gets an instance of a table reader.

Declaration
Python
get_table_reader((O2GTableType)table_type, (O2GResponse)response = None) -> typing.object

Parameters
table_type

The identifier of the table (see O2GTableType).
response

An instance of O2GResponse to get a reader for.
The method passes the instance to the method create_reader. The default value of the parameter is None, in this case the method takes the response returned by the method O2GLoginRules.get_table_refresh_response and passes it to create_reader.
