public method AO2GTableListener.on_deleted

Brief

Processes a notification about the row deletion from a table.

Declaration
Python
on_deleted((str)row_id, (O2GRow)row_data) -> None

Parameters
row_id

The identifier of a row. The parameter has the value of the row identifier for a specific trading table. For example, for the Accounts table, it has the value of the AccountID field.
row_data

The object representing a row of a table. In order to process the parameter, you need to know what table it belongs to. This could be accomplished by calling the O2GRow.table_type method.

Details

To get notifications about row deletions from a specific table, an instance of the class implementing the AO2GTableListener abstract class must be subscribed to the Delete operation of this table. It is accompished by calling the O2GTable.subscribe_update method with the O2GTableUpdateType.DELETE parameter.
