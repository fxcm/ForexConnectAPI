account_info_user Table

Brief

The article describes the report table containing information about the account owner.

Details

The table contains information about the owner of the account the report is requested for. The identifier of the table is account_info_user.

Column identifier

Column data type

Description

owner_name

STRING

In case of individual accounts, the name of the account owner in the format First M. Last.
In case of joint accounts, the name of the primary account owner in the format First M. Last.
In case of all other accounts (corporate, trust, partnership, LLC), the business name of the organization.

owner_name_joint

STRING

In case of individual accounts, the value is empty.
In case of joint accounts, the name of the secondary account owner in the format First M. Last.
In case of all other accounts (corporate, trust, partnership, LLC), the name of the organization's contact person in the format First M. Last.

owner_address

STRING

The address of the account owner in the format Address1 Address2 City, State Zip code Country.
