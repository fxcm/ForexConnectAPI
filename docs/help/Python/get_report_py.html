Getting Combined Account Statement Report

Brief

The article explains how to get a Combined Account Statement report.

Details

Combined Account Statement (also known as CAS) aggregates all information pertinent to an account. The report includes details on all trades, orders, and transactions on the account during the report statement period.

To get a CAS report in your Python script, you must perform the following steps:

  1. Log in.

  2. Get the URL for the CAS report by calling the O2GSession.get_report_URL method.

  3. Load the report.

  4. Log out.

import os
from urllib.request import urlopen
import datetime
 
from forexconnect import fxcorepy, ForexConnect
 
 
def session_status_changed(session: fxcorepy.O2GSession,
                           status: fxcorepy.AO2GSessionStatus.O2GSessionStatus):
    print("Trading session status: " + str(status))
 
 
def main():
 
    with ForexConnect() as fx:
        try:
            fx.login("user_id", "password", "fxcorporate.com/Hosts.jsp",
                     "Demo", session_status_callback=session_status_changed)
 
            url = fx.session.get_report_url("str_account_id",
                                            datetime.datetime.strptime("MM.DD.YYYY HH:MM:SS", '%m.%d.%Y %H:%M:%S').replace(tzinfo=datetime.timezone.utc),
                                            datetime.datetime.strptime("MM.DD.YYYY HH:MM:SS", '%m.%d.%Y %H:%M:%S').replace(tzinfo=datetime.timezone.utc),
                                            "html", None)
 
            file_name = os.path.join(os.getcwd(), "account_id")
            file_name += ".html"
 
            response = urlopen(url)
 
            with open(file_name, 'wb') as file:
                file.write(response.read())
 
        except Exception as e:
            print("Exception: " + str(e))
 
        try:
            fx.logout()
        except Exception as e:
            print("Exception: " + str(e))
 
 
if __name__ == "__main__":
    main()
