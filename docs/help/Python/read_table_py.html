Getting Data from Trading Tables

Brief

The article explains how to get data from trading tables.

Details

When logged in, ForexConnect API creates and maintains in-memory representations of trading tables by default. You can convert trading tables to pandas.DataFrame objects, get trading tables by rows, as well as get trading table rows that contain certain column values.

When you use the methods mentioned below to get data from trading tables, the received data is not automatically updated. For instructions on how to get trading table updates, see the Getting Trading Table Updates article.

To get data from a trading table in your Python script, you must perform the following steps:

  1. Log in.

  2. Get the necessary table by calling the ForexConnect.get_table method.

  3. Get data from the table:

    • To convert the table to a pandas.DataFrame, call the method Common.convert_table_to_dataframe.

    • To get the table data by rows, call the method O2GTable.get_row.

    • To get table rows that contain certain column values, call one of the following methods:

      • To get rows containing a specified column value, call the method O2GTable.get_rows_by_column_value.

      • To get rows containing any of the specified column values, call the method O2GTable.get_rows_by_column_values.

      • To get rows containing a number of specified column values that satisfy specified conditions, call the method O2GTable.get_rows_by_multi_column_values.

      • To get rows containing column values that satisfy a specified condition, call the method O2GTable.get_rows_by_condition.

  4. Log out.
