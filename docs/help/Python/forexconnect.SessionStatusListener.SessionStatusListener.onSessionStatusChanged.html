public method SessionStatusListener.on_session_status_changed

Brief

Implements the method AO2GSessionStatus.on_session_status_changed and calls the function that processes notifications about the session status change. The function is passed in the constructor or set by the method set_callback.

Details

The class also implements additional logic. When the session status changes to CONNECTED or DISCONNECTED, an instance of the class fires an event. An event is also fired when the method on_login_failed is called. When the session status changes to TRADING_SESSION_REQUESTED, an instance of the class calls the method O2GSession.set_trading_session and passes the passed Session ID and PIN code to it.
