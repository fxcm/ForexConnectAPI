static public method O2GTransport.set_proxy

Brief

Configures the proxy server settings.

Declaration
Python
set_proxy((str)proxy_host, (int)i_port, (str)user = None, (str)password = None) -> None

Parameters
proxy_host

The host name or IP address of the proxy.
i_port

The proxy port.
user

If the proxy requires authorization, specify the user name in this parameter. If the proxy does not require authorization, please specify 0 (null-pointer) in this parameter.
The default value of the parameter is None
password

If the proxy requires authorization, specify the password in this parameter. If the proxy does not require authorization, please specify 0 (null-pointer) in this parameter.
The default value of the parameter is None

Details

The specified proxy settings affect all connections which will be established after this method is called. These parameters will be used during the next call of the O2GSession.login method.
