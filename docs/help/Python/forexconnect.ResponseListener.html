class ResponseListener

Parents
AO2GResponseListener

Brief

The class implements the AO2GResponseListener abstract class and calls the passed functions on request completions/failures and table updates.

Details

To process notifications on request completions/failures and table updates, create an instance of the class and pass it in the method ForexConnect.send_request or ForexConnect.send_request_async.

The instance of ResponseListener will call the appropriate callback function passed in the constructor when one of the following methods is called: on_request_completed, on_request_failed, on_tables_updates.

The module is forexconnect

Public Properties

error

Gets a string representation of an error that occurred when processing a request.

response

Gets an instance of O2GResponse if it has been received.

Public Methods

__init__

The constructor.

on_request_completed

Implements the method AO2GEachRowListener.on_request_completed and calls the function that processes notifications about the successful request completion. The function is passed in the constructor.

on_request_failed

Implements the method AO2GEachRowListener.on_request_failed and calls the function that processes notifications about the request failure. The function is passed in the constructor.

on_tables_updates

Implements the method AO2GEachRowListener.on_tables_updates and calls the function that processes notifications about table updates. The function is passed in the constructor.

reset

Resets the response listener after a response is received.

stop_waiting

Stops waiting for a response.

wait_event
