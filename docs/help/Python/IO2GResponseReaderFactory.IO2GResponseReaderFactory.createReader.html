public method O2GResponseReaderFactory.create_reader

Brief

Creates a reader to process a response that is provided by the trading server automatically.

Declaration
Python
create_reader((O2GResponse)response) -> typing.Any

Parameters
response

A response object.

Details

The method returns an instance of the reader or a bool value for the MARGIN_REQUIREMENTS_RESPONSE response type. In case the response has a wrong type or is broken, the method returns None.

The response types and their appropriate readers (or a value for the MARGIN_REQUIREMENTS_RESPONSE response type) returned by the method are listed in the following table.

O2GResponseType

Appropriate reader/Value

O2GGenericTableResponseReader

O2GGenericTableResponseReader

O2GGenericTableResponseReader

O2GGenericTableResponseReader

O2GOrderResponseReader

GET_LAST_ORDER_UPDATE

O2GLastOrderUpdateResponseReader

TABLES_UPDATES

O2GTablesUpdatesReader

MARGIN_REQUIREMENTS_RESPONSE

A bool value specifying whether the margin requirements are loaded or not.
