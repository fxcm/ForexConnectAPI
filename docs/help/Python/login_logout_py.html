Logging In

Brief

The article explains how to log in step by step.

Details

To perform any operation using ForexConnect API, you must log in to the FXCM server, i.e. have a connected trading session.
See the detailed description of session statuses in the Session Statuses article.

Before logging in, you must include ForexConnect API in your script.

To log in, you must perform the following steps:

  1. Import the ForexConnect class from the forexconnect module.

  2. To get notifications on trading session status changes, define the session_status_callback function that will be called by the ForexConnect.login method. For example:

    def session_status_changed(session: fxcorepy.O2GSession,
                           status: fxcorepy.AO2GSessionStatus.O2GSessionStatus):
    print("Trading session status: " + str(status))

    This step is optional.

  3. Call the ForexConnect.login method and catch exceptions. For example:

    with ForexConnect() as fx:
    try:
        fx.login("user_id", "password", "url",
                 "connection", session_status_callback=session_status_changed)
 
        #TBD: your ForexConnect API logic here
 
    except Exception as e:
        print("Exception: " + str(e))

    The login operation is synchronous. It blocks the process until the trading session is connected or login fails. If the login fails, the method will raise an exception. If you want to get notifications on the trading session status change, you should define the function session_status_callback in the method (see step 2).

  4. When you are done, log out using the ForexConnect.logout method in a separate try module and catch exceptions. For example:

        try:
        fx.logout()
    except Exception as e:
        print("Exception: " + str(e))

                           status: fxcorepy.AO2GSessionStatus.O2GSessionStatus):
    print("Trading session status: " + str(status))

    with ForexConnect() as fx:
