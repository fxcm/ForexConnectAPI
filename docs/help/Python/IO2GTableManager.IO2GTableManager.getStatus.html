public property O2GTableManager.status

Brief

Gets a table manager status.

Declaration
Python
status -> O2GTableManagerStatus

Details

The table manager status defines whether the trading tables data can be used or not.

The possible return values are listed in O2GTableManagerStatus.

Note: The method has the following disadvantage: your thread is suspended and cannot be used while you are waiting for the TABLES_LOADED status. For example, if your application requires loading of the GUI components or some other processing that is not directly dependent on the status of the table manager, these processes are also suspended. If you cannot afford a temporary suspension of the main thread, your application must implement the AO2GTableManagerListener.on_status_changed method to get a table manager status.
