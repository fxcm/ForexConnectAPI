class O2GCommissionsProvider

Brief

Checks commissions.

Details

To create an instance of O2GCommissionsProvider use the O2GSession.get_commissions_provider method.

The module is forexconnect.fxcorepy.

Public Properties

status

Gets the commission status.

Public Methods

calc_close_commission

Calculates the commission incurred on closing a position with specified parameters.

calc_open_commission

Calculates the commission incurred on opening a position with specified parameters.

calc_total_commission

Calculates the commission incurred both on opening and closing a position with specified parameters.

get_commission_descriptions

Gets the commission description.

subscribe

Subscribes to commission updates.

unsubscribe

Unsubscribes from commission updates.
