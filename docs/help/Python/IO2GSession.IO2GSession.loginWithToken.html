public method O2GSession.login_with_token

Brief

Starts the connection with the specified trade server using SSO token

Declaration
Python
login_with_token((str)user, (str)token, (str)url, (str)connection) -> bool

Parameters
user

The user name.
token

SSO token.
url

The URL of the server. The URL must be a full URL, including the path to the host descriptor, for example "http://www.fxcorporate.com/Hosts.jsp"
connection

The name of the connection, for example "Demo" or "Real".

Details

The connection parameters are exactly the same as can be used for the Trading Station application or ForexConnect API.

The method returns True if the login has been sucessfully initialized. The method returns False if the session status is other than DISCONNECTED.

Please note that the method only starts the connection. To watch the connection status, please implement the AO2GSessionStatus abstract class and subscribe an instance of the implementing class to the session using the subscribe_session_status method.
