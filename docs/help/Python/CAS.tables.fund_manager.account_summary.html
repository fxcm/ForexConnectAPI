account_summary Table

Brief

The article describes the Account Summary table of the report.

Details

The Account Summary table contains summarized information about all transactions that were posted to the account during the report statement period as well as certain account information (further referred to as account properties), such as:

  • Account balance (at the start/end date of the report statement period)

  • Floating profit/loss (at the end date of the report statement period)

  • Equity (at the end date of the report statement period)

  • Used and usable margin (at the end date of the report statement period)

The identifier of the table is account_summary.

Column identifier

Column data type

Description

type_id

INTEGER

The unique identification number of the transaction type or account property (see the table below).

code

STRING

The short (or abbreviated) localized code of the transaction type (see the table below).
For an account property, the value is empty.

description

STRING

The default localized description of the transaction type or account property (see the table below).

The default description may be accompanied by additional notes provided by the operator who performed the transaction.

amount

DOUBLE

The total amount of funds credited or debited to the account during the report statement period or the total amount of the account property.

The value can be either positive or negative. A positive value indicates that the amount was credited, a negative value indicates that the amount was debited.

The amount is expressed in the account denomination currency.

% change

No

The ratio of the account loss to the amount of funds invested in the account for the period from the account open date till the end date of the report statement period. The value can be zero or negative. A zero value indicates a ratio of less than 10 percent. A negative value indicates a ratio of 10 percent or greater.
The account property is displayed if the report account is subject to MIFID II (Directive on Markets in Financial Instruments repealing Directive 2004/39/EC and the Regulation on Markets in Financial Instruments) requirements.

Note: Most of the transactions listed in the table are used in special circumstances. If you have an account that is affected by these transactions, you will be aware of what they relate to. Most accounts are not affected by any of these transactions.
