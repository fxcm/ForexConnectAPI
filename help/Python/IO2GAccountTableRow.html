class O2GAccountTableRow

Parents
O2GAccountRow

Brief

The class provides access to the account information and calculated fields.

Details

The class represents a single row of the Accounts table.

If you need access to the current account information, get an instance of the class by calling any of the following methods of the O2GTable (type Account) class.

If you want to track the Accounts table updates, you have to Subscribe for the table updates. See Getting trading table updates article for details.

The module is forexconnect.fxcorepy

Public Properties

Gets the maximum amount of an order that is allowed on the account.

columns

margin_call_flag
