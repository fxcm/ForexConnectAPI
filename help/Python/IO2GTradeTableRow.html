class O2GTradeTableRow

Parents
O2GTradeRow

Brief

The class provides access to the open position information and calculated fields.

Details

The class represents a single row of the Trades table.

If you need access to the current trade information, get an instance of the class by calling any of the following methods of the O2GTable (type TRADES) class.

If you want to track the Accounts table updates, you have to Subscribe for the table updates. See Getting trading table updates article for details.

The module is forexconnect.fxcorepy
