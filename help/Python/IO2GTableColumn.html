class O2GTableColumn

Brief

The class provides access to a trading table column.

Details

Each column of the trading tables has a unique identifier and a data type. These properties of a column can be accessed by using the id and the type properties of the class, respectively. To define whether a column is a key column of the table, use the property is_key.

To get an instance of the class, use one of the implementations of the O2GTableColumnCollection get method.

The module is forexconnect.fxcorepy.

Public Properties

id

Gets the unique identifier of a column.

is_key

Defines whether the column is the key column of the table.

type

Gets the data type of a column.
