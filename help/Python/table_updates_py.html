Getting Trading Table Updates

Brief

The article explains how to get trading table updates.

Details

When logged in, ForexConnect API creates and maintains in-memory representations of trading tables by default. Then you may need to know if rows of a trading table have been added, removed, or changed.
For example, you may want to get updated offers from the Offers table or when opening a position, you may want to make sure that the corresponding trade has been added to the Trades table.

To get trading table updates in your Python script, you must perform the following steps:

  1. Log in.

  2. Define a callback function or functions (on_add_callback, on_delete_callback, on_change_callback) that will be called by the Common.subscribe_table_updates method when a trading table row is added, removed, or changed. For example:

    def on_added_trade(_, __, trade_row):
    if trade_row.open_order_id == order_id:
        print("For the order: OrderID = {0} the following positions have been opened:".format(order_id))
        print("Trade ID: {0:s}; Amount: {1:d}; Rate: {2:.5f}".format(trade_row.trade_id, trade_row.amount,
                                                                     trade_row.open_rate))

  3. Get the necessary table by calling the ForexConnect.get_table method.

  4. Create a table listener and subscribe to the table updates by calling the Common.subscribe_table_updates method. For example:

    trades_listener = Common.subscribe_table_updates(trades_table, on_add_callback=on_added_trade)

    The callback function will be called in a separate thread. You have to synchronize its results with your main thread. Find a link to sample scripts demonstrating implementation of the method Common.subscribe_table_updates below.

  5. Before logging out, unsubscribe from table updates by calling the method TableListener.unsubscribe For example:

    trades_listener.unsubscribe()

  6. Log out.
