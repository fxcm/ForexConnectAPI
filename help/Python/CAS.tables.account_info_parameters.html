account_info_parameters Table

Brief

The article describes the report table containing account information.

Details

The table contains information about the account the report is requested for. The identifier of the table is account_info_parameters.

Column identifier

Column data type

Description

account_kind

INTEGER

The kind of the account. Possible values:

32

Self-traded account, funds manager account (only LAMM), managed account (only LAMM)

36

Funds manager account (only PAMM)

38

Managed account (only PAMM)

account

STRING

The identifier of the account (as it is displayed in the Trading Station).

open_date

DATE

The date and time when the account was opened. The open date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

status

STRING

The status of the account. Possible values:

Active

The account is fully operational.

Locked

The account is locked for security reasons; trading is restricted.

Closed

The account is closed.

margin_call_flag

STRING

The account trading limitation state. Each state defines which trade operations can and cannot be performed on the account. Possible values:

N

No limitations (no limitations are imposed on the account operations)

Y

Margin call (all positions are liquidated, new positions cannot be opened)

W

Warning of a possible margin call or aware margin (positions can be closed, new positions cannot be opened)

Q

Equity stop (all positions are liquidated, new positions cannot be opened up to the end of the trading day)

A

Equity alert (positions can be closed, new positions cannot be opened up to the end of the trading day)
