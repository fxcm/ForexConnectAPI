class O2GClosedTradeTableRow

Parents
O2GClosedTradeRow

Brief

The class provides access to the closed position information.

Details

The class represents a single row of the Closed Trades table.

If you need access to the current closed position information, get an instance of the class by calling any of the following methods of the O2GTable (type Closed Trades) class.

If you want to track the Accounts table updates, you have to Subscribe for the table updates. See Getting trading table updates article for details.

The module is forexconnect.fxcorepy
