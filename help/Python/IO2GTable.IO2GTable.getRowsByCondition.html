public method O2GTable.get_rows_by_condition

Brief

Gets rows containing column values that satisfy a specified condition.

Declaration
Python
get_rows_by_condition((str)column_name, (O2GRelationalOperators)condition, (typing.List[typing.object])column_values) -> O2GTableIterator

Parameters
column_name

The name of a column in the table.
condition

The condition the table column values must satisfy.
column_values

The array of two values (column_values[0] and column_values[1]) of the column specified by the column_name parameter.

Details

This method allows finding all rows containing column values that satisfy a specified condition.

For the relational operator BETWEEN, the method uses both column_values[0] and column_values[1]: column_values[0] is used as a lower value and column_values[1] is used as an upper value.
For all other O2GRelationalOperators, the method uses only column_values[0], while column_values[1] must be None.

Note that if the column value is boolean, the values specified in column_values must be boolean.

If no row is found, the method returns an empty iterator.

from forexconnect import fxcorepy, ForexConnect
 
#Get notifications on the trading session status changes
def session_status_changed(session: fxcorepy.O2GSession,
                           status: fxcorepy.AO2GSessionStatus.O2GSessionStatus):
    print("Trading session status: " + str(status))
 
 
def main():
 
    with ForexConnect() as fx:
        try:
           #Log in
           fx.login("user_id", "password", "fxcorporate.com/Hosts.jsp",
                    "connection", session_status_callback=session_status_changed)
 
           #Get Trades table and print rows with PL less than specified amount
           trades_table = fx.get_table(ForexConnect.TRADES)
           trades_rows = trades_table.get_rows_by_condition("pl", fxcorepy.O2GRelationalOperators.LESS_THAN, [-70.0, None])
           for row in trades_rows:
               print ("OfferID: {0}, Amount: {1},  BuySell: {2}, PL: {3}".format(row.offer_id, row.amount,
                      row.buy_sell, row.pl))
 
        except Exception as e:
            print("Exception: " + str(e))
 
        #Log out
        try:
            fx.logout()
        except Exception as e:
            print("Exception: " + str(e))
 
 
if __name__ == "__main__":
    main()
