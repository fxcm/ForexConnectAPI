class TableListener

Parents
AO2GTableListener

Brief

The class implements the abstract class AO2GTableListener and calls the passed functions on the appropriate trading tables events: adding/changing/deleting of rows and table status changes.

Details

An instance of the class is created when the method Common.subscribe_table_updates is called. The instance is created with the callback functions passed in the method and is subscribed to updates of a certain table.

To process notifications on the appropriate trading tables events: adding/changing/deleting of rows and table status changes, create an instance of the class using the method Common.createTableListener and subscribe it to a certain table using the method subscribe.

The instance of TableListener will call the appropriate callback function passed in the constructor when one of the following methods is called: on_added, on_changed, on_deleted, on_status_changed.

When the listener is not needed anymore or before the logout, unsubscribe the listener using the method unsubscribe.

Note: You must not use the method unsubscribe while any of the callback functions is being called.

The module is forexconnect.

Public Methods

__init__

The constructor.

on_added

Implements the method AO2GTableListener.on_added and calls the function that processes notifications about the row addition to a table. The function is passed in the constructor.

on_changed

Implements the method AO2GTableListener.on_changed and calls the function that processes notifications about the row change in a table. The function is passed in the constructor.

on_deleted

Implements the method AO2GTableListener.on_deleted and calls the function that processes notifications about the row deletion from a table. The function is passed in the constructor.

on_status_changed

Implements the method AO2GTableListener.on_status_changed and calls the function that processes notifications about the table status change. The function is passed in the constructor.

subscribe

Subscribes a table listener to updates of a certain table.

unsubscribe

Unsubscribes a table listener from table updates.
