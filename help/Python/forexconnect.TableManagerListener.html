class TableManagerListener

Parents
AO2GTableManagerListener

Brief

The class implements the abstract class AO2GTableManagerListener and calls the passed function when the table manager status changes.

Details

An instance of the class is created when the method ForexConnect.login or ForexConnect.login_with_token is called. The instance is created with the callback function passed in the method.

The instance of the class TableManagerListener will call the callback function passed in the constructor or set by the method set_callback when the method on_status_changed is called.

The module is forexconnect.

Public Properties

status

Gets the current status of the table manager.

Public Methods

__init__

The constructor.

on_status_changed

Implements the method AO2GTableManagerListener.on_status_changed and calls the function that processes notifications about the table manager status change. The function is passed in the constructor or set by the set_callback method.

reset

Resets the flag that is set when the table manager status changes to TABLES_LOADED or TABLES_LOAD_FAILED.

set_callback

Sets a callback function.

wait_event

Starts waiting for a flag that is set when the table manager status changes to TABLES_LOADED or TABLES_LOAD_FAILED.
