class O2GTimeframeCollection

Brief

A collection of the timeframes available for the session.

Details

The type is an iterable type.

The type is an indexable collection type.

The type of an element is O2GTimeframe.

Use the method O2GRequestFactory.time_frame_collection to get an instance of the available timeframes collection.

The module is forexconnect.fxcorepy

Public Properties

size

Gets the number of timeframe elements in the collection.
