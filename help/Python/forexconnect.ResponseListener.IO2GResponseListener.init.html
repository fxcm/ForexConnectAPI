on_request_completed_callback

The function that is called when a notification about a request completion is received. The function takes request_id and O2GResponse as arguments. Returns True if a response is received and the listener stopped waiting for a response for this request. Returns False if a response is received and the listener continues to wait for a response, in this case the user must use the method stop_waiting to stop the waiting. The default value of the parameter is None, in this case the behavior is tha same as if the function returned True.
on_request_failed_callback

The function that is called when a notification about a request failure is received. The function takes request_id and a string representation of an error as arguments. Returns True if a response is received and the listener stopped waiting for a response for this request. Returns False if a response is received and the listener continues to wait for a response, in this case the user must use the method stop_waiting to stop the waiting. The default value of the parameter is None, in this case the behavior is tha same as if the function returned True.
on_tables_updates_callback

The function that is called when a notification about a table update is received. The default value of the parameter is None.
