Including ForexConnect API in Python in Your Script

Brief

The article describes how to include ForexConnect API in Python in your script.

Details

To use ForexConnect API in your Python script, you must perform the following steps:

  1. Install the forexconnect package using Python's standard pip package manager.

    • To install ForexConnect from the PyPI repository, execute the following command in a console:

      python -m pip install forexconnect

    • To install ForexConnect from a .whl file, execute the following command in a console:

      python -m pip install <forexconnect wheel file name>

  2. Make sure all the required dependencies are installed or install them from requirements.txt:

    python -m pip install -r requirements.txt

    You can find requirements.txt file in the ../forexconnect/lib/ folder or download it from github.

  3. Import the fxcorepy module. Add the following line to your script:

    from forexconnect import fxcorepy

  4. Import other classes from the forexconnect module as needed. For example:

    from forexconnect import ForexConnect, ResponseListener, Common
