Deleting Order

Brief

The article explains how to delete an order.

Details

To delete an order in your Python script, you must perform the following steps:

  1. Log in.

  2. Create a request for deleting an order by calling the Forexconnect.create_request method. You must specify the following request parameters:

    • fxcorepy.O2GRequestParamsEnum.COMMAND must be fxcorepy.Constants.Commands.DELETE_ORDER

    • fxcorepy.O2GRequestParamsEnum.ACCOUNT_ID must be the account ID of the account the order is created on.

    • fxcorepy.O2GRequestParamsEnum.ORDER_ID must be the order ID of the order you want to delete.

    For example:

        request = fx.create_request({
        fxcorepy.O2GRequestParamsEnum.COMMAND: fxcorepy.Constants.Commands.DELETE_ORDER,
        fxcorepy.O2GRequestParamsEnum.ACCOUNT_ID: "account_id",
        fxcorepy.O2GRequestParamsEnum.ORDER_ID: "order_id"
    })

  3. When the order is deleted, it is deleted from the Orders table. To make sure that the order has been deleted, i.e. a row with the corresponding order ID has been deleted from the table, you need to monitor Orders table updates.
    For this, define the on_delete_callback callback function that will be called after you subscribe to the table updates, get the the Orders table, create a table listener and subscribe it to the table updates.
    The callback function will be called in a separate thread. You can synchronize its results with your main thread by setting an event. In the following example, on_delete_callback collects all rows deleted from the table and sets an event if an order row with the corresponding order ID is deleted.

      def on_delete_order(self, _, __, order_row):
      order_id = order_row.order_id
      self.__deleted_orders[order_id] = order_row
      if self.__order_id == order_id:
          self.__event.set()
 
    orders_table = fx.get_table(ForexConnect.ORDERS)
    orders_listener = Common.subscribe_table_updates(orders_table, on_delete_callback=on_deleted_order)

  4. Send the request for deleting the order by calling the method ForexConnect.send_request.

        try:
        resp = fx.send_request(request)
 
    except Exception as e:
        print("Exception: " + str(e))
        orders_listener.unsubscribe()
   ...

  5. Wait for the order to be deleted from the table. The order row might be deleted from the table before the response is received, so you need to check if an order row with the corresponding order ID has been already collected. For example:

      def wait(self, time, order_id):
      self.__order_id = order_id
 
      order_row = self.find_order(order_id)
      if order_row is not None:
          return order_row
 
      self.__event.wait(time)
 
      return self.find_order(order_id)
 
  def find_order(self, order_id):
      if order_id in self.__deleted_orders:
          return self.__deleted_orders[order_id]
      else:
          return None
 
 ...
 
      is_deleted = orders_monitor.wait(30, order_id)
      if not is_deleted:
          print("Response waiting timeout expired.\n")
      else:
          print("The order has been deleted. Order ID: {0:s}".format(order_row.order_id))
          sleep(1)

  6. Unsubscribe the table listener from table updates. For example:

          orders_listener.unsubscribe()

  7. Log out.
