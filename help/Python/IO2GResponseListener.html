class AO2GResponseListener

Brief

The abstract class provides the method signatures to process notifications about request completions, request failures and tables updates.

Details

The class must be implemented by an application in order to process responses provided by the server as a result of trading tables updates. To process these notifications, you must use the AO2GResponseListener.on_tables_updates method.

For complete details of processing the response contents, refer to the O2GResponse class documentation.

If you want to use the methods of the AO2GResponseListener class, you must create a class that implements these abstract class.

An instance of the class implementing the AO2GResponseListener abstract class must be subscribed to a session object. It is accomplished by calling the O2GSession.subscribe_response method.

The subscribed instance must be unsubscribed from a session object after calling the O2GSession.logout method. It is accomplished by calling the O2GSession.unsubscribe_response method.

The module is forexconnect.fxcorepy

Public Methods

on_request_completed

Processes a notification about the successful request completion.

on_request_failed

Processes notification about a request failure.

on_tables_updates

Processes notifications about tables updates.
