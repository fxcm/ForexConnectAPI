enum QuotesManagerErrorCode

Brief

The Quotes Manager error codes.

Details

The module is forexconnect.fxcorepy

Static Public Fields

BAD_ARGUMENT

Invalid arguments were specified in a function call.

LIMIT_REACHED

The error can occur when the cache size limit is active and Quotes Manager cannot clear enough space to execute the command.

LOADING_ERROR

An error occurred while reading data from the Quotes Manager server.

LOCKED

The Quotes Manager cache is locked by other task.

OTHER_ERROR

Some other error occurred.

QUOTES_CACHE_BUSY

An error occurred while using the Quotes Manager cache - it's busy for a long time.

QUOTES_CACHE_CORRUPTED

Quotes Manager cache is corrupted and QuotesManager could not automatically repair it.

QUOTES_CATALOG_BUSY

An error occurred while using the Quotes Manager cache's local catalog - it's busy for a long time.

QUOTES_LOADER_ERROR

An error occurred while loading quotes using ForexConnect.

QUOTES_NOT_FOUND

Some file was not found on a server.

QUOTES_SERVER_CONNECTION_ERROR

An error occurred while connecting to a QuotesServer.
