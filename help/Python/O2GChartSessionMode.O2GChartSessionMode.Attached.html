static public field O2GChartSessionMode.ATTACHED

Brief

This mode is useful if you need historical data. This mode is used by default.

Details

Simulates work without separating a chart channel. No separate statuses for the chart session are received; the trading session is connected only if the chart session is connected.
If the system is unable connect to the chart server, the login process stops and 'login failed' (on_chart_session_login_failed) returns.
Programs developed previously do not require changes.
