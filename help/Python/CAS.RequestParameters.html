Report Request Parameters

Brief

The article describes the request parameters of the report.

Details

Parameter name

Description

reporttype

The report name. The value is combined_account_statement.

cn

The connection name of the database the report data is retrieved from. Your credentials and access rights are verified in this database.

account

The identifier of the account (as it is displayed in the Trading Station) the report is requested for.

from

The start date of the report statement period.

If the start date is earlier than the account open date, the value is the account open date.

The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

till

The end date of the report statement period.

If the end date is earlier than the account open date, the value is the account open date.

The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

timeformat

The time zone used to display the date and time in the report. This parameter is optional. Possible values:

Server

The time zone of the server. If the tzname parameter is used, it is ignored.

UTC

The Coordinated Universal Time time zone. If the tzname parameter is used, it is ignored.

Financial

Counts 17:00 New York time as 00:00 and displays the date and time as if 17:00 were midnight. If the tzname parameter is used, it is ignored.

Local

The time zone of the local device. For this value, the tzname parameter is used.

tzname

The user time zone named according to the rules described in Wikipedia, see Names of time zones. This parameter is optional. It has sense only when the timeformat value is Local.
Example: America/New_York
