static public method Common.get_account

Brief

Gets an instance of O2GAccountRow by Account ID or searches for a trading account with no limitations on account operations and/or satisfying a certain condition.

Declaration
Python
get_account((ForexConnect)fc, (str)account_id=None, (typing.Callable[[O2GAccountRow], bool])additional_check_func=None) -> O2GAccountRow

Parameters
fc

An instance of ForexConnect.
account_id

The unique identifier of the account. The default value of the parameter is None, in this case the method searches for a first account that satisfies the following conditions: the account kind is 32 or 36, the margin call flag is N.
additional_check_func

The function that is called if a user specifies an additional check for the account. The function takes an instance of O2GAccountRow as an argument. The function returns True if the condition of the additional check is satisfied, and False if it is not satisfied. The default value of the parameter is None.
