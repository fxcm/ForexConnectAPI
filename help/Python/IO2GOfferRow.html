class O2GOfferRow

Parents
O2GRow

Brief

The class provides access to offer information.

Details

An instance of the class can be obtained by the following methods:

Method/Use

Prerequisites

O2GGenericTableResponseReader.get_row
This method is used to get the initial offer information after a session with the trading server is established.
This method provides access to a single offer. If you want to receive information about multiple offers, call this method in a loop.

Depending on the trading server settings, the Offers table may or may not be loaded by the server automatically during the login process.
To determine whether the table is loaded or not and what follow-up action is required to get the offer information, use the returned value of the O2GLoginRules.is_table_loaded_by_default method:

  • If the table is loaded, you can get the offer information by using the O2GLoginRules.get_table_refresh_response method;

  • Otherwise, you must create a request to load the table by using the O2GRequestFactory.create_refresh_table_request method. You must obtain a response to this request by implementing of the AO2GResponseListener.on_request_completed method.

Both methods use the O2GResponse object of the O2GResponseType.GetOffers type.
You must parse this object by using the O2GGenericTableResponseReader object.

O2GTablesUpdatesReader.get_offer_row

This method is used to get offer information updates.
This method provides access to a single offer. If you need information about multiple offers, call this method in a loop.

To receive offer information updates, you must implement the AO2GResponseListener.on_tables_updates method. The received O2GResponse object is of the O2GResponseType.TablesUpdates type.
You must parse this object by using the O2GTablesUpdatesReader object.
