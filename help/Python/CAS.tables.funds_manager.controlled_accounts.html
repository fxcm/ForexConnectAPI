controlled_accounts Table

Brief

The article describes the Controlled Account table of the report.

Details

The Controlled Account table contains information about all managed accounts mapped to the funds manager account. The information mainly includes the account balance at the start (from) and end (till) dates of the report statement period (see Combined Account Statement: Report Request Parameters). The identifier of the table is controlled_accounts.

All data rows are arranged in ascending order by the managed account identifier (controlled_account).

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

controlled_account

STRING

The identifier of the managed account (as it is displayed in the Trading Station).

beginning_balance

DOUBLE

The amount of funds in the managed account at the start date of the report statement period. The beginning balance does not reflect floating (unrealized) profit/loss.

Note that if the account was mapped to the funds manager account after the start date of the report statement period, the beginning balance will be the actual balance of that account at the time of mapping.

The beginning balance is expressed in the account denomination currency.

ending_balance

DOUBLE

The amount of funds in the managed account at the end date of the report statement period. The ending balance does not reflect floating (unrealized) profit/loss.

The ending balance is expressed in the account denomination currency.

equity

DOUBLE

The amount of funds in the managed account at the end date of the report statement period. The equity reflects floating (unrealized) profit/loss.

The equity is expressed in the account denomination currency.
