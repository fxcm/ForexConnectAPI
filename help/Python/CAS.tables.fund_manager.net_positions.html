net_positions Table

Brief

The article describes the Net Positions table of the report.

Details

The Net Positions table contains information about all net positions that remain open at the end (till) date of the report statement period (see Combined Account Statement: Report Request Parameters). The identifier of the table is net_positions.

The table is available only if the account is set to a netting trading mode (the value of the position_maintenance costant is either 0 or D).

The table has data rows and a total row. One data row contains information about one net position. The total row contains summarized information about all net positions. Data rows can be distinguished from a total row by the value of the grouping_type column. If the value is 1, the row is a data row. If the value is 2, the row is a total row. Note that though a total row includes information for all columns of the table, only some of this information is relevant and makes sense, namely:

  • Used margin (margin)

  • Floating profit/loss (floating_pl)

  • Broker commission (comm)

  • Rollover interest (rollover)

  • Net profit/loss (net_pl)

If no information is found for the report statement period, the table has only a header row.

Column identifier

Column data type

Description

grouping_type

INTEGER

Defines whether the row is a data row or a total row.
The value 1 indicates a data row, the value 2 indicates a total row.

symbol

STRING

The instrument traded.
The value makes sense only for data rows.

precision

INTEGER

The precision (i.e. the number of digits after the decimal point) of the instrument price.
The value makes sense only for data rows.

value_date

DATE

The date when the net position that was not offset during the same trading day is automatically closed. The date has the format YYYY-MM-DD hh:mm:ss, where:

YYYY

Year

MM

Month (01-12)

DD

Day of month (01-31)

hh

Hour (00-23)

mm

Minute (00-59)

ss

Second (00-59)

Makes sense only for accounts with the Day Netting trading mode (the value of the position_maintenance constant is D).

sell_qty

DOUBLE

The amount of the instrument sold.

The value can be either positive or zero. A positive value indicates that the net position is a sell net position, a zero value indicates that the net position is a buy net position.
The value makes sense only for data rows.

In case of FX instruments, the sell quantity is expressed in the base currency of the instrument.
In case of CFD instruments, the sell quantity is expressed in contracts.

sell_average_price

DOUBLE

The average price the amount of the instrument (sell_qty) was sold at.
The value makes sense only for data rows.

buy_average_price

DOUBLE

The average price the amount of the instrument (buy_qty) was bought at.
The value makes sense only for data rows.

buy_qty

DOUBLE

The amount of the instrument bought.

The value can be either positive or zero. A positive value indicates that the net position is a buy net position, a zero value indicates that the net position is a sell net position.
The value makes sense only for data rows.

In case of FX instruments, the buy quantity is expressed in the base currency of the instrument.
In case of CFD instruments, the buy quantity is expressed in contracts.

net_qty

DOUBLE

The difference between the bought and sold amounts of the instrument.
The value makes sense only for data rows.

Since the hedging capability is not aplicable to accounts with a netting trading mode, the net quantity will always be equal to either buy_qty or sell_qty.

In case of FX instruments, the net quantity is expressed in the base currency of the instrument.
In case of CFD instruments, the net quantity is expressed in contracts.

margin

DOUBLE

The amount of funds committed to maintain the net position(s) (used margin).
The value makes sense for data rows as well as for a total row.

The margin is expressed in the account denomination currency.

floating_pl

DOUBLE

The amount of floating (unrealized) profit or loss at the end date of the report statement period. This amount excludes additional charges, such as broker commission (comm) and rollover interest (rollover).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The floating profit/loss is expressed in the account denomination currency.

markups

DOUBLE

The markups applied to the net position. If a position is opened by several executions, the markups for the position is a sum of markups for these executions.
The column is displayed if the report account is subject to MIFID II (Directive on Markets in Financial Instruments repealing Directive 2004/39/EC and the Regulation on Markets in Financial Instruments) requirements.

The markups are expressed in pips.

The value makes sense only for data rows.

comm

DOUBLE

The amount of broker commission charged during the entire lifetime of the net position(s).

The value can be either negative or zero. A negative value indicates that the commission was charged, a zero value indicates that the commission was not charged.
The value makes sense for data rows as well as for a total row.

The commission is expressed in the account denomination currency.

rollover

DOUBLE

The amount of rollover interest earned or paid during the entire lifetime of the net position(s).

The value can be either positive or negative. A positive value indicates that the rollover was earned, a negative value indicates that the rollover was paid.
The value makes sense for data rows as well as for a total row.

The rollover is expressed in the account denomination currency.

net_pl

DOUBLE

The amount of floating (unrealized) profit or loss at the end date of the report statement period. This amount includes additional charges, such as broker commission (comm) and rollover interest (rollover).

The value can be either positive or negative. A positive value indicates profit, a negative value indicates loss.
The value makes sense for data rows as well as for a total row.

The net profit/loss is expressed in the account denomination currency.

created_by

STRING

The name (login) of the user who placed the latest order the net position was opened/updated/closed by.
The value makes sense only for data rows.

executed_by

STRING

In case of immediate orders, the name (login) of the user who placed the latest order the net position was opened/updated/closed by.
In case of conditional orders, the name of the server that executed the latest order for the net position.
The value makes sense only for data rows.
