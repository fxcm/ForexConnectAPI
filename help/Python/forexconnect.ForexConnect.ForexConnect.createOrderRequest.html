public method ForexConnect.create_order_request

Brief

Creates a request for creating an order of a specified type using specified parameters.

Declaration
Python
create_order_request((str)order_type, (Commands)command = fxcorepy.Constants.Commands.CreateOrder, (kwargs)str) -> O2GRequest

Parameters
order_type

The type of the order. See Contansts.Orders.
command

The command. The default value of the parameter is fxcorepy.Constants.Commands.CreateOrder.
str

The order parameters. For a full list of possible request parameters, see O2GRequestParamsEnum.

Details

For a detailed description of the request parameters to be filled for each order type, see the section Order Request Parameters.

Example:

       request = fx.create_order_request(
           order_type=LE,
           OFFER_ID=1,
           ACCOUNT_ID=1234567,
           BUY_SELL=B,
           AMOUNT=10,
           RATE=1,12345,
       )

For details, see ForexConnect.createRequest.
