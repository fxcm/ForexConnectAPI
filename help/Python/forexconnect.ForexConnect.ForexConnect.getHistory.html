public method ForexConnect.get_history

Brief

Gets price history of a certain instrument with a certain timeframe for a specified period or a certain number of bars/ticks.

Declaration
Python
get_history((str)instrument, (str)timeframe, (datetime.datetime)date_from = None, (datetime.datetime)date_to = None, (int)quotes_count = -1, candle_open_price_mode=fxcorepy.O2GCandleOpenPriceMode.PREVIOUS_CLOSE) -> numpy.ndarray

Parameters
instrument

The symbol of the instrument. The instrument must be one of the instruments the ForexConnect session is subscribed to.

To check the list of the instruments, use the Offers table. The name of the instrument is kept in the Instrument column of the table.
timeframe

The unique identifier of the timeframe. For details, see What is Timeframe?.
date_from

The date/time of the oldest bar/tick in the history.

To get quotes_count bars ending at the date_to, use the value None.

The date/time must be in the UTC time zone.

The default value of the parameter is None.
date_to

The date/time of the most recent bar/tick in the history.

To get the history up to the most recent ("now") bar/tick, use the value None.

The date/time must be in the UTC time zone.

The default value of the parameter is None.
quotes_count

The number of bars/ticks in the history. The parameter is optional.

The default value of the parameter is -1.

If the parameter is not specified or its value is -1, you will get all bars between the date_from and date_to or 300 bars (the maximum number of bars in a price history by default), which is less.
In case -1 is used, the date_from must not be None.
candle_open_price_mode

The candles open price mode that indicates how the open price is determined. See O2GCandleOpenPriceMode.
The default value of the parameter is fxcorepy.O2GCandleOpenPriceMode.PREVIOUS_CLOSE.

Details

Returns a collection of ticks (for the t1 timeframe) or bars (for all other timeframes).
