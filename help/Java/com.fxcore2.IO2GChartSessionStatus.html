interface IO2GChartSessionStatus

Brief

Interface provides method signatures to process notifications about chart session status changes and login failures.

Details

Interface must be implemented by the application in order to process the chart status change of the session object.
This interface is useful only if you work with chart session in DETACHED mode.

When a user tries to login, the chart session status changes to CONNECTING.

If a login fails, the status changes to DISCONNECTED and the server returns an error message explaining why the login has failed. If you want to capture what has gone wrong, use the onChartSessionLoginFailed method of the interface.

If a login is successful, the session status changes to CONNECTED. If you want to capture and process every status change of the session object, use the onChartSessionStatusChanged method of the interface. For a complete list of the session statuses, see O2GChartSessionStatusCode.

If you want to use the methods of the IO2GChartSessionStatus interface, you must create a class that implements the interface. For example,
public class ChartSessionStatusListener implements IO2GChartSessionStatus { }

An instance of the class implementing the IO2GChartSessionStatus interface must be subscribed to the session object before calling the O2GSession.login method. It is accomplished by calling the O2GSession.subscribeChartSessionStatus method. For example,

mSession = O2GTransport.createSession();
ChartSessionStatusListener statusListener = new ChartSessionStatusListener(mSession, mDBName, mPin);
mSession.subscribeChartSessionStatus(statusListener);

The subscribed instance must be unsubscribed from the session object after calling the O2GSession.logout method, but before calling the O2GSession.dispose method. It is accomplished by calling the O2GSession.unsubscribeChartSessionStatus method. For example,

mSession.logout();
mSession.unsubscribeChartSessionStatus(statusListener);
mSession.dispose();

The namespace is com.fxcore2.

Public Methods

onChartSessionLoginFailed

Processes notification about the login failure.

onChartSessionStatusChanged

Processes notifications about the session status change.
