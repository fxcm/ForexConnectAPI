static public method QuotesManagerFactory.create

Brief

Deprecated method. Creates an instance of the Quotes Manager.

Declaration
Java
static QuotesManager  create (String host, int port, String dataPath, int tradingDayOffset, int tradingWeekOffset) throws java.lang.IllegalArgumentException, QuotesManagerError

Parameters
host

The host name of the Quotes Manager server.
port

The TCP port of the Quotes Manager server.
dataPath

The absolute path on the local computer where the cache data must be located.

If the folder does not exist, it will be automatically created.
tradingDayOffset

The offset of the beginning of the trading day against the calendar day midnight, expressed in hours.

The value is used for calculation of H2 and longer candles.

Use any value if you are going to get only H1 or shorter candles.

See CandlePeriod for further discussion of this value.
tradingWeekOffset

The offset of the beginning of the trading week against the trading day of Sunday, expressed in days.

The value is used for calculation of week candles only.

Use any value if you are not going to get week candles.

See CandlePeriod for further discussion of this value.

Exceptions
java.lang.IllegalArgumentException

The exception is thrown if argument is null.
QuotesManagerError

The exception is thrown if some error occurred during the creation.
