class O2GProgressiveMarginLevels

Brief

The collection of progressive margin levels.

Details

The class provides methods for getting the progressive margin requirements.

It is used in the function O2GTradingSettingsProvider.getProgressiveMarginLevels to get the progressive margin requirements for the specified instrument.

The namespace is com.fxcore2.

Public Methods

getCount

Gets the number of levels in the collection.

getFrom

Gets the From amount threshold for the specified level.

getMarginPerContract

Gets the amount of margin requirements per contract for the specified level.

getTill

Gets the Till (inclusive) amount threshold for the specified level.
