public method O2GTableManager.getTable

Brief

Gets an instance of a trading table.

Declaration
Java
O2GTable  getTable (O2GTableType eTableType)

Parameters
eTableType

A trading table. The possible values are shown below.

Details

The method returns an instance of one of the O2GTable subclasses. You must cast the returned value to the responding type. The examples are shown below.

eTableType parameter

Returned O2GTable subclass

Syntax example

MESSAGES

O2GMessagesTable

O2GMessagesTable messagesTable = (O2GMessagesTable)tableManager.getTable(O2GTableType.MESSAGES);

CLOSED_TRADES

O2GClosedTradesTable

O2GClosedTradesTable closedTradesTable = (O2GClosedTradesTable)tableManager.getTable(O2GTableType.CLOSED_TRADES);

TRADES

O2GTradesTable

O2GTradesTable tradesTable = (O2GTradesTable)tableManager.getTable(O2GTableType.TRADES);

ORDERS

O2GOrdersTable

O2GOrdersTable ordersTable = (O2GOrdersTable)tableManager.getTable(O2GTableType.ORDERS);

ACCOUNTS

O2GAccountsTable

O2GAccountsTable accountsTable = (O2GAccountsTable)tableManager.getTable(O2GTableType.ACCOUNTS);

OFFERS

O2GOffersTable

O2GOffersTable offersTable = (O2GOffersTable)tableManager.getTable(O2GTableType.OFFERS);

SUMMARY

O2GSummaryTable

O2GSummaryTable summaryTable = (O2GSummaryTable)tableManager.getTable(O2GTableType.SUMMARY);
