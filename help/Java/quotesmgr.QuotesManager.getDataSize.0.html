public method QuotesManager.getDataSize

Brief

Gets the amount of data used by the cache for the specified instrument, base timeframe and year.

Declaration
Java
long  getDataSize (String instrument, String timeframe, int year) throws java.lang.IllegalStateException, java.lang.IllegalArgumentException, QuotesManagerError

Parameters
instrument

The name of the instrument.
timeframe

The name of the base timeframe.

See How does Quotes Manager Work (Business Logic)? for an explanation of what the base timeframe is. Use getBaseTimeframes() to get the list of base timeframes.
year

The year (e.g. 1998 or 2005).

To get the list of instruments and the range of dates where the price data is available, use the getInstruments() method.

Exceptions
java.lang.IllegalStateException

The exception is thrown if the quotes manager is already disposed.
java.lang.IllegalArgumentException

The exception is thrown if argument is null.
QuotesManagerError

The exception is thrown if some error has occurred.
