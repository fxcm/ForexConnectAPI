public method O2GAccountsTable.getNextRowByMultiColumnValues

Brief

Gets the next row from O2GAccountsTable based on the multiple columns values.

Declaration
Java
O2GAccountTableRow  getNextRowByMultiColumnValues (String[] columnNames, O2GRelationalOperators[] conditions, Object[] columnValues, O2GLogicalOperators logicalOperator, O2GTableIterator iterator)

Parameters
columnNames

The array of column names in the Accounts table. For example, AccountID, AccountKind.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the columns specified by the columnNames parameter. For example, if you want to search the Accounts table for trading accounts without a margin call flag only, the columnNames parameter value is an array of AccountKind and MarginCallFlag, and the columnValues parameter is an array of 32 and N.
iterator

The table iterator.

Details

If the row is not found, the method returns null.
Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.

Example

Get trading accounts without the margin call flag from the Accounts table [show]

Get trading accounts without the margin call flag from the Accounts table [hide]

    public void enumerateTradingAccounts() {
        O2GAccountsTable accounts = (O2GAccountsTable)mTblMgr.getTable(O2GTableType.ACCOUNTS);
        O2GTableIterator iterator = new O2GTableIterator();
        String[] columnNames = new String[] { "AccountKind", "MarginCallFlag" };
        Object[] columnValues = new Object[] { "32", "N" };
        O2GAccountTableRow account = accounts.getNextRowByMultiColumnValues(columnNames, columnValues, iterator);
        while (account != null) {
            System.out.println(String.format("AccountID=%s, AccountName=%s, Equity=%s, GrossPL=%s",
                    account.getAccountID(), account.getAccountName(), account.getEquity(), account.getGrossPL()));
            account = accounts.getNextRowByMultiColumnValues(columnNames, columnValues, iterator);
        }
    }
