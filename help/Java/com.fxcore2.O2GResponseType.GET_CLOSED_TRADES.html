static public field O2GResponseType.GET_CLOSED_TRADES

Brief

The constant represents the type of a response to a request for initial closed position information.

Details

If your application uses the O2GTableManager, the Closed Trades table is always loaded during the login process. This information is kept in an O2GClosedTradesTable object.

If your application does not use the O2GTableManager, the initial closed position information needs to be requested.
Depending on the trading server settings, the Closed Trades table may or may not be loaded by the server automatically during the login process. To determine whether the table is loaded or not and what follow-up action is required to obtain the O2GResponseType.GET_CLOSED_TRADES response, use the returned value of the O2GLoginRules.isTableLoadedByDefault method with the O2GTableType.CLOSED_TRADES argument:

Returned Value

Follow-up action

true

Call the O2GLoginRules.getTableRefreshResponse method. For example,

O2GResponse closedTradesResponse = loginRules.getTableRefreshResponse(O2GTableType.CLOSED_TRADES);

The method returns an instance of the O2GResponse class of the O2GResponseType.GET_CLOSED_TRADES type.

false

Create a request to get initial closed position information by using the O2GRequestFactory.createRefreshTableRequest method. For example,

O2GRequest request = requestFactory.createRefreshTableRequest(O2GTableType.CLOSED_TRADES);

In this case, an instance of the O2GResponse class is the response parameter in your implementation of the IO2GResponseListener.onRequestCompleted method.

To process the contents of a response object of the O2GResponseType.GET_CLOSED_TRADES type, use an instance of the O2GClosedTradesTableResponseReader class.
