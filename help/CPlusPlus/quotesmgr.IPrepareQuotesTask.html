class IPrepareQuotesTask

Parents
Task

Brief

The Prepare Quotes task.

Details

The task must be used in order to load all data, necessary to get the price history of the specified instrument and timeframe, into the cache. As only the data that has already been loaded into the cache can be received, this task must be performed every time before the application requests prices from the Quotes Manager.

You can check whether all required prices are already loaded into the cache using IQuotesManager::areQuotesPrepared.

The quotes catalog must be updated before the Prepare Quotes task is executed. See IUpdateQuotesCatalogTask for details.

The task may be quite long, so, in order to let the application display the progress, it is split into subtasks. The update() method of the callback will be called for each subtask separately. In order to get the number of the subtasks, you can use the getTotalSubtasks() method.

The result of the task will be reported into the instance of IPrepareQuotesCallback associated with the task when the task is created.

The task has no intermediate result, it only changes the internal Quotes Manager data.

Use IQuotesManager::createPrepareQuotesTask() to create the task.

The task does not provide any quotes to the application. To load quotes from the cache, use IReceiveBarQuotesTask.

The type defined in the quotesmgr2 library. The namespace is quotesmgr.
