public method IO2GTradesTable.getNextRowByMultiColumnValues

Brief

Gets the next row from IO2GTradesTable based on the multiple columns values.

Declaration
C++
virtual bool  getNextRowByMultiColumnValues (const int columnCount, const char *columnNames[], O2GRelationalOperators conditions[], const void *columnValues[], IO2GTableIterator &iterator, IO2GTradeTableRow *&row) = 0

Parameters
columnCount

Number of columns in which the search is to be performed.
columnNames

The array of column names in the Trades table.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the columns specified by the columnNames parameter. For example, if you want to search the Trades table for positions by account 12345 and EUR/USD instrument, the columnNames parameter value is an array of AccountID and OfferID, the columnValues parameter is an array of 12345 and 1, the columnCount parameter value is 2.
iterator

The table iterator.
row

[out] The row fetched.

Details

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all except Between relational operators for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo. For example, columnRelationals[] = {EqualTo, EqualTo, EqualTo}.

Example

Get open positions by specified AccountID and OfferIDwith GrossPL more than 0 from the Trades table.Which corresponds to SQL query SELECT row FROM TradesTable WHERE AccountID = "12345" AND OfferID = "1" AND GrossPL > 0. [show]

    O2G2Ptr<IO2GTradesTable> tradesTable = (IO2GTradesTable *)tableManager->getTable(Trades);
 
    std::string accountID = "12345";
    std::string offerID = "1";
    double grossPL = 0;
 
    bool found = false;
    IO2GTableIterator iterator;
    IO2GTradeTableRow *trade = NULL;
 
    const char *columnNames[] = {"AccountID", "OfferID", "GrossPL"};
    O2GRelationalOperators columnRelationals[] = {EqualTo, EqualTo, GreaterThan};
    const void *columnValues[] = {(void *)accountID.c_str(), (void *)offerID.c_str(), (void *)&grossPL};
 
    while (tradesTable->getNextRowByColumnValues(3, columnNames, columnRelationals, columnValues, iterator, trade))
    {
        found = true;
        std::cout << "TradeID: " << trade->getTradeID() <<
                     " OfferID = " << trade->getOfferID() <<
                     " Amount = " << trade->getAmount() << std::endl;
        trade->release();
    }
    if (!found)
        std::cout << "No matching trades found." << std::endl;

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
