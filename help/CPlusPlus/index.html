ForexConnect API User Guide

This user guide covers the following APIs:

  • ForexConnect API
    ForexConnect API is an API designed to trade Forex and CFD instruments. It offers the same functionality that is available on the FXCM Trading Station. This includes creating all of the available order types, getting offers, managing positions, downloading historical prices, getting account reports, and more. Any connection compatible with the FXCM Trading Station/Marketscope or with an older version of Order2Go API is also compatible with this API.

  • Price History API and Quotes Manager API
    The Quotes Manager API and the Price History API provide an alternative and more efficient way to get historical prices.

See also When to Use Each API to Get Historical Prices?
