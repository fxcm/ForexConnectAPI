Including Quotes Manager API on Linux/MacOS

Brief

The article discusses how to use Quotes Manager API in C++ on Linux or MacOS.

Details

To use Quotes Manager API in your C++ application, you should:

  1. Place supporting shared libraries in the same directory where your application program is located. Alternatively, you can place supporting shared libraries in the /usr/lib directory.

  2. Add libquotesmgr2 to the list of libraries in the linker options. For example, if you use gcc, the option will be -lquotesmgr2. The path to the directory containing the libraries (e.g. /ForexConnectAPI/lib) can be specified by the -L/ForexConnectAPI/lib option.

  3. Include the header file in your code using the directive #include "quotesmgr/quotesmgr2.h". The path to the directory containing the headers (e.g. /ForexConnectAPI/include/quotesmgr) can be specified by the -I/ForexConnectAPI/include/quotesmgr option.

Quotes Manager API dependencies

If you use the Quotes Manager API, the ForexConnect API and the Price History API must be included to the application.

System Requirements

  • Mac OS X Yosemite or higher.

  • Xcode 8.3.3 or higher.

  • Quotes Manager API cannot be used in sandboxed Mac applications.
