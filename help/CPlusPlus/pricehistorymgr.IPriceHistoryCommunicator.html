interface IPriceHistoryCommunicator

Parents
IAddRef

Brief

The interface to the Price History API communicator.

Details

This interface is used for performing all operations and activities required to get the price history data using this API.

To create an instance of the communicator, use the PriceHistoryCommunicatorFactory::createCommunicator() method.

The instance of the communicator must be kept as long as the corresponding trading session is kept. Do not release the instance until the trading session is successfully logged off and all listeners are unsubscribed.

The type defined in the pricehistorymgr library. The namespace is pricehistorymgr.
