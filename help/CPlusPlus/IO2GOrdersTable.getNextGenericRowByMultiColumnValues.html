public method IO2GOrdersTable.getNextGenericRowByMultiColumnValues

Brief

Gets the next row from IO2GTable based on the multiple columns values.

Declaration
C++
virtual bool  getNextGenericRowByMultiColumnValues (const int columnCount, const char *columnNames[], O2GRelationalOperators conditions[], const void *columnValues[], IO2GTableIterator &iterator, IO2GRow *&row) = 0

Parameters
columnCount

Number of columns in which the search is to be performed.
columnNames

The array of column names.
conditions

The array of relations which should be met for table values.
columnValues

The array of values of the columns specified by the columnNames parameter.
iterator

The table iterator.
row

[out] The row fetched.

Details

If the row is not found, the method returns false.

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
