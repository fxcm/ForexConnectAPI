enum WeekendCandleMode

Brief

The options of handling price data during weekends.

Details

While 17:00NYT, Friday till 17:00NYT, Sunday is a non-trading time, prices actually start to be broadcasted between 12:00 and 14:00 of Sunday. There are three options how these prices can be handled for 1-Day candles. The choice depends on preferences of the user and his method of the market data interpretation and analysis.

  • These prices can be simply ignored (this is the default behavior of the FXCM trading system).

  • These prices can be formed into a separate Sunday candle.

  • These prices can be added to the Monday candle, so, it actually starts not at 17:00NYT, Sunday, but at 12:00NYT, Sunday.

[Since QuotesManager 2.6] These options affect timeframes from m1 to D1.

One of these options can be chosen using the IQuotesManager::setWeekendCandleMode() method.

The type defined in the quotesmgr2 library. The namespace is quotesmgr.

Static Public Fields

WeekendCandleHide

Ignore the prices during non-trading hours.

WeekendCandleMergeToNextWeek

Add prices during non-trading hours to the first candle of the week.

WeekendCandleShow

Make a separate candle reflecting price movement during non-trading hours.
