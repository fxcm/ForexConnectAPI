class IReceiveBarQuotesTask

Parents
Task

Brief

The Receive Quotes task.

Details

The task must be used to actually receive the price history data from the cache.

Before the task can be executed, quotes must be loaded into the cache using the IPrepareQuotesTask task.

The result of the task will be reported into the instance of IReceiveBarQuotesCallback associated with the task when the task is created.

Every single bar of the history will be sent into the callback by calling the IReceiveBarQuotesCallback::nextBarQuote() method of the callback. The older quotes will be sent first.

Use IQuotesManager::createReceiveBarQuotesTask() to create the task.

The type defined in the quotesmgr2 library. The namespace is quotesmgr.
