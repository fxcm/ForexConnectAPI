public method IQuotesManager::createUpdateQuotesCatalogTask

Brief

Creates the task to update the catalog of the quotes for the specified instrument.

Declaration
C++
virtual IUpdateQuotesCatalogTask*  createUpdateQuotesCatalogTask (const char *instrument, const char *timeframe, IUpdateQuotesCatalogCallback *callback, IError **error = 0) = 0

Parameters
instrument

The instrument name.
timeframe

The name of the timeframe to which the catalog must be updated.

Use the name of the timeframe to get, the quotes manager will automatically determine which base timeframe catalogs must be updated.
callback

The implementation of the task callback.
error

[output] If not NULL and an error occurred it will contain a pointer to a detailed error description object. It must be released by a caller after the use.

Details

See IUpdateQuotesCatalogTask for details.

Please note that this method does NOT start the task. To start the task, use the executeTask() method.
