enum IError::Code

Brief

The Quotes Manager error codes.

Details

The type defined in the quotesmgr2 library. The namespace is quotesmgr.

Static Public Fields

BadArgument

Invalid arguments were specified in a function call.

LimitReached

The error can occur when the cache size limit is active and Quotes Manager cannot clear enough space to execute the command. The problem is temporary, the command may be repeated after a few minutes.

LoadingError

The error can occur while updating a catalog or preparing quotes. An error occurred while reading data from the Quotes Manager server.

Locked

The Quotes Manager cache is locked by other task. For example ReceiveQuotesTask cannot be executed if at this time RemoveQuotesTask is executing and vice versa.

OtherError

Some other error occurred.

QuotesCacheBusy

An error occurred while using the Quotes Manager cache — it's busy for a long time. The error may occur because there are too many PrepareQuotesTasks are executing at this time probably in different processes.

QuotesCacheCorrupted

This is a critical error, it means that the Quotes Manager cache is corrupted and QuotesManager could not automatically repair it.

QuotesCatalogBusy

An error occurred while using the Quotes Manager cache's local catalog — it’s busy for a long time. The error may occur because there are too many PrepareQuotesTasks are executed at this time probably in different processes.

QuotesLoaderError

An error occurred while loading quotes using ForexConnect. E.g. the current trading day quotes.

QuotesNotFound

The error can occur while preparing quotes. Some file was not found on a server. It's an internal server side error.

QuotesServerConnectionError

The error can occur while updating a catalog or preparing quotes. An error occurred while connecting to a QuotesServer.
