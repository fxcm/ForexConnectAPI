public method IInstrument::getBaseTimeframes

Brief

Gets a collection of base timeframes for this instrument.

Declaration
C++
virtual IBaseTimeframes*  getBaseTimeframes () = 0

Details

See How does Quotes Manager Work (Business Logic)? for an explanation of what the base timeframe is. But an instrument may support additional base large timeframes (D1, W1, M1). It allows to receive quotes in wide range of dates for these timeframes, wider than for general base timeframes. E.g. XAU D1 prices are available from 1920.

This method returns a list of all base timeframes of the instrument. These timeframes may be used when getting a range of quotes using methods getOldestQuoteDate() and getLatestQuoteDate(). Release the collection after use.
