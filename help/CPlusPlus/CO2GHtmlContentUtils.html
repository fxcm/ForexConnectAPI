class CO2GHtmlContentUtils

Brief

The class converts relative paths specified as tag parameters to absolute paths.

Details

The class replaces relative paths for parameters (href and src) with tags (link, a, img) with absolute paths.

The method of the class is static. One does not need to have an instance of the class.

Example: Convert relative paths to absolute paths

 [show]

 [hide]

    std::string htmlContent = "<html>\n<head>\n<link rel = \"stylesheet\" type=\"text/css\" href=\"\\css/all.css\" /> \n</head>
    \n<body>\n<a href=\"/test.aspx\">Example</a>\n<a href=\"http://example.com\">Example</a>\n<img src=\"/images/example.jpg\"/>
    \n<img src=\"http://example.com/images/example.jpg\"/>\n</body>\n</html>";
    std::string prefix = "http://example.com";
 
    std::string htmlContentWithAbsPath = O2GHtmlContentUtils::replaceRelativePathWithAbsolute(htmlContent.c_str(), prefix.c_str());
