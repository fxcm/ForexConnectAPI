static public method PriceHistoryCommunicatorFactory::createCommunicator

Brief

Creates an instance of the Price History API communicator.

Declaration
C++
static IPriceHistoryCommunicator  createCommunicator (IO2GSession *o2gSession, const char *quotesManagerDataPath, IError **error)

Parameters
o2gSession

An instance of the ForexConnect trading session.

The session must not be logged in yet at the moment this method is called.
quotesManagerDataPath

The local path where the Quotes Manager API must store its cache data.
error

[output] If not NULL and an error occurred it will contain a pointer to a detailed error description object. It must be released by a caller after the use.

Returns

The method returns a new communicator instance. If an error occurred returns NULL.

Details

The instance of the price history communicator does not become ready immediately upon creation. In order to make it usable, the application must:

  • Log in the trading session.

  • Then wait until the price communicator object switches into the ready state.

Example [hide]

#include "ForexConnect.h"
#include "pricehistorymgr/pricehistorymgr.h"
 
using namespace pricehistorymgr;
 
class MyClass : public IO2GSessionStatus, public IPriceHistoryCommunicatorListener
{
    ...
    IO2GSession *mTradingSession;
    IPriceHistoryCommunicator *mPriceHistoryCommunicator;
 
    ...
    void initialize(const char *userName,
                    const char *password,
                    const char *url,
                    const char *terminal,
                    const char *cachePath)
    {
        //create the trading session and subscribe for it's event
        mTradingSession = CO2GTransport::createSession();
        mTradingSession->subscribeSessionStatus(this);
 
        //create a price history communicator and subscribe for its events
        IError *error;
        mPriceHistoryCommunicator =
            PriceHistoryCommunicatorFactory::createCommunicator(mTradingSession, cachePath, &error);
 
        if (mPriceHistoryCommunicator == NULL)
        {
            if (error != NULL)
            {
                //process error
                //...
                error->release();
            }
            return;
        }
 
        mPriceHistoryCommunicator->addListener(this);
 
        //Start login process
        mTradingSession->login(userName, password, url, terminal);
    }
};
