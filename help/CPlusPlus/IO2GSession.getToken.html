public method IO2GSession.getToken

Brief

Gets the number of characters in a token and stores the token in a buffer.

Declaration
C++
virtual int  getToken (char * tokenBuffer, int bufferSize) = 0

Parameters
tokenBuffer

A buffer to the token.
bufferSize

The size of the buffer.

Returns

  • If successful and the value of the tokenBuffer parameter is zero, the required size of the buffer (the required number of characters).

  • If successful and the value of the tokenBuffer parameter is nonzero, the number of characters in the token.

  • If unsuccessful, a negative value. See O2GTokenError for details.
