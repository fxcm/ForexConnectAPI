enum O2GCommissionUnitType

Brief

The enum specifies a set of constants representing the commission unit type.

Details

The commission unit type can be obtained by calling the IO2GCommissionDescription.getUnitType method.

Static Public Fields

CommissionPerBasisPoints

The constant represents the Basis Points commission type.

CommissionPerLot

The constant represents the Per Lot commission type.

CommissionPerLotConv

The constant represents the Per Lot Conversion commission type.

CommissionPerOrder

The constant represents the Per Order commission type.

CommissionPerOrderConv

The constant represents the Per Order Conversion commission type.

CommissionPerTrade

The constant represents the Per Trade commission type.

CommissionTypeUnknown

The constant represents an unknown commission type.
