public method IO2GMessagesTable.getNextRowByCondition

Brief

Gets the next row from IO2GMessagesTableRow based on any of the condition.

Declaration
C++
virtual bool  getNextRowByCondition (const char *columnName, O2GRelationalOperators condition, const void *columnValues[], IO2GTableIterator &iterator, IO2GMessageTableRow *&row) = 0

Parameters
columnName

The name of a column in the Messages table.
condition

The relation which should be met for table values.
columnValues

The array of values of the column specified by the columnName parameter. For example, if you want to search the Messages table for the messages which were received during last 2 hours, columnName parameter value is Time and the columnValues parameter is an array of two dates (the lower and the upper values) you want to search between.
iterator

The table iterator.
row

[out] The row fetched.

Details

This method allows finding all rows that correspond to the specified condition.
The method gets value for searching from columnValues[0] for all O2GRelationalOperators. For Between operator the method uses both columnValues[0] and columnValues[1]. columnValues[0] is used as the lower value and columnValues[1] is used as upper value.

If the row is not found, the method returns false.

The wildcard like ? or * can be used for string data type. For example: "U100*", "???D3*", "*D3*".

The method supports all relational operators including Between for predicates of searching fields. If set NULL instead of O2GRelationalOperators, the method interprets the value as EqualTo.

Example

Get messages by market conditions type of the message content from a specific sender with the time when the recipient receives the message. Which corresponds to SQL query SELECT rows FROM MessagesTable WHERE Feature = "5" AND From = "login" AND Time >= [today, 00:00:00.000]. [show]

    bool found = false;
    IO2GTableIterator iterator;
    IO2GMessageTableRow *message = NULL;
 
    const char *columnNames[] = {"Feature", "From", "Time"};
    O2GRelationalOperators columnRelationals[] = {EqualTo, EqualTo, GreaterThanOrEqualTo};
    const void *columnValues[] = {(void *)feature.c_str(), (void *)loginID.c_str(), (void *)&time};
 
    while (messagesTable->getNextRowByMultiColumnValues(3, columnNames, columnValues, iterator, message))
    {

        std::cout << "MessageID: " << message->getMsgID() <<
                     " From = " << message->getFrom() <<
                     " Text = " << message->getText() << std::endl;
        message->release();
    }
    if (!found)
        std::cout << "No matching messages found." << std::endl;

Note: The returned row contains the current columns values. The values are not automatically updated. To monitor changes, use IO2GTableListener.onChanged. The row interface is thread-safe. The returned row can be used in different threads without synchronization.
