Including ForexConnect API on Win32/Win64

Brief

The article discusses how to use ForexConnect API in C++ on Win32/Win64.

Details

To use ForexConnect API in your C++ application, you must perform the following steps:

  1. Place your application in the directory where the supporting .dll files are located (usually, in the bin folder containing gsexpat.dll, fxmsg.dll, gstools2.dll, etc.). For example, if the C:\Program Files\Candleworks\ForexConnectAPI\bin directory contains these libraries, the post-build event command line may look like this:

    copy "C:\Program Files\Candleworks\ForexConnectAPI\bin\*.dll" "$(TargetDir)"

    Alternatively, you can build you application in the directory containing the supporting .dll files.

  2. Add the include subfolder of the directory where ForexConnect API is installed to additional include directories of the project. So, if ForexConnect API is installed in C:\Program Files\Candleworks\ForexConnectAPI, add the C:\Program Files\Candleworks\ForexConnectAPI\include directory as an additional include directory.

  3. In the stdafx.h file, add the following line:

    #include "ForexConnect.h"

  4. Add the lib subfolder of the directory where ForexConnect API is installed to additional library directories of the project. So, if ForexConnect API is installed in C:\Program Files\Candleworks\ForexConnectAPI, add the C:\Program Files\Candleworks\ForexConnectAPI\lib directory as an additional library directory. Add ForexConnect.lib as an additional dependency for the linker input.

Note: ForexConnect API interfaces use ASCII strings, so Character Set of Configuration Properties will be Not set.
