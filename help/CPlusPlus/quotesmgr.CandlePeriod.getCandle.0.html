static public method CandlePeriod::getCandle

Brief

Gets the date and time of the candle (bar) to which the specified time belongs to.

Declaration
C++
static bool  getCandle (double time, double &start, double &end, CandlePeriod::Unit unit, int unitLength, int startHourOffset, int startWeekOffset)

Parameters
time

Date/time that belongs to the candle (bar).
start

[output] The start of the candle (bar). The time is greater or equal to the start of the bar.
end

[output] The end of the candle (bar). The time is less than the end of the bar (in other words, it is the date/time of the next candle (bar).
unit

The time measurement units of the timeframe.
unitLength

The length of the timeframe in the specified units.
startHourOffset

The offset of the trading day start against the calendar day midnight, expressed in hours. For example, FXCM's trading day starts at 17:00 NYT of the previous day, so the offset if -7 hours.

See the class documentation for discussion of this parameter.
startWeekOffset

The offset of the trading week start against the Sunday, expressed in days. For example, FXCM's trading week starts Saturday 17:00 NYT (i.e. Sunday trading day), so the offset is 0 day. This parameter is used only in case the unit is Week.

See the class documentation for discussion of this parameter.
