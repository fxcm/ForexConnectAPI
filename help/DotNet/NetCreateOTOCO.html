Create OTOCO Order

To create an OTOCO (one-triggers-OCO) order you should create an OTO (one-triggers-others) order, where the primary order is an Entry order, and the secondary order is an OCO (one-cancels-others) order.

To create an OTOCO order group:

1) Create an O2GValueMap for an OTO order and fill only one field:

Valuemap field

Datatype

Description

Command

string

The command. Must be CreateOTO.

The field is obligatory.

2) Create an O2GValueMap for primary order and fill it as for a regular entry order.

3) Create an IO2GValueMap for an OCO order and fill only one field:

Parameter name

Datatype

Description

Command

string

The command. Must be CreateOCO.

The field is obligatory.

4) Create an IO2GValueMap for each entry order of an OCO group you want to create and fill it as for a regular entry order.

5) Append each entry order value map to the main value map using the O2GValueMap.appendChild method in the following way:

5.1) Append OTO primary order value map from step 2 to the OTO value map using the IO2GValueMap.appendChild method.

5.2) Append each entry order of an OCO group value map from step 4 to the OCO value map using the IO2GValueMap.appendChild method.

5.3) Append OCO value map to OTO value map using the IO2GValueMap.appendChild method.

6) Pass the OTO O2GValueMap to the O2GRequestFactory.createOrderRequest method.

Limitations:

1) Only entry orders or other OTO/OTOCO groups can be joined into OTOCO. However, entry orders with attached stops/limits, either regular or ELS, can be joined into OTOCO.

2) All entry orders must be created for the same account.

Returns:

The createOrderRequest method will return an O2GRequest (the main request) containing child requests. If 3 entry orders are created, 3 child requests will be returned. Note that you will receive responses to the child requests and will not receive a response to the main request.

    // Helper method for creating valueMap for one order
    static  O2GValueMap CreateOrder(string sAccountID, sOrderParams orderParams)
    {
        return CreateOrder(sAccountID, orderParams.offerID, orderParams.rate, orderParams.amount, orderParams.buySell, orderParams.orderType);
    }
 
    static void PrepareAndCreateOTOCO()
    {
        string sAccountID, sOfferID;
        int iBaseAmount;
        double dPointSize, dAskRate, dBidRate;
        bool bParamsOK = PrepareParamsFromLoginRules(out sAccountID, out sOfferID, out iBaseAmount, out dPointSize, out dAskRate, out dBidRate);
        if (!bParamsOK)
        {
            return;
        }
        double dRate = dAskRate;
        sOrderParams[] orders = new sOrderParams[3];
        orders[0].amount = orders[1].amount = orders[2].amount = 10 * iBaseAmount;
        orders[0].offerID = orders[1].offerID = orders[2].offerID = sOfferID;
 
        orders[0].buySell = Constants.Buy;
        orders[0].orderType = Constants.Orders.LimitEntry;
        orders[0].rate = dRate - 50 * dPointSize;
 
        orders[1].buySell = Constants.Sell;
        orders[1].orderType = Constants.Orders.StopEntry;
        orders[1].rate = orders[0].rate - 10 * dPointSize;
 
        orders[2].buySell = Constants.Buy;
        orders[2].orderType = Constants.Orders.StopEntry;
        orders[2].rate = orders[0].rate + 20 * dPointSize;
 
        O2GValueMap otoPrimary = CreateOrder(sAccountID, orders[0]);
        O2GValueMap ocoFirst = CreateOrder(sAccountID, orders[1]);
        O2GValueMap ocoSecond = CreateOrder(sAccountID, orders[2]);
        CreateOTOCO(otoPrimary, ocoFirst, ocoSecond);
    }
 
    static void CreateOTOCO(O2GValueMap otoPrimary, O2GValueMap ocoFirst, O2GValueMap ocoSecond)
    {
        O2GRequestFactory factory = session.getRequestFactory();
        if (factory != null)
        {
           // create OTOCO command
           O2GValueMap otocoValuemap = factory.createValueMap();
           otocoValuemap.setString(O2GRequestParamsEnum.Command, Constants.Commands.CreateOTO);
 
           // append OTO primary order
           otocoValuemap.appendChild(otoPrimary);
 
           // create OCO command
           O2GValueMap ocoValuemap = factory.createValueMap();
           ocoValuemap.setString(O2GRequestParamsEnum.Command, Constants.Commands.CreateOCO);
 
           // append OCO orders
           ocoValuemap.appendChild(ocoFirst);
           ocoValuemap.appendChild(ocoSecond);

           // attach OCO order
           otocoValuemap.appendChild(ocoValuemap);
 
           // create request from valueMap
           O2GRequest request = factory.createOrderRequest(otocoValuemap);
           if (request == null)
           {
               Console.WriteLine("Order's request can not be created: " + factory.getLastError());
           }
           else
           {
               session.sendRequest(request);
           }
        }
    }
