static public method QuotesManagerFactory.setProxy

Brief

Deprecated method. Sets the HTTP proxy parameters.

Declaration
C#
void  setProxy (string proxyHost, int port, string user, string password)

Parameters
proxyHost

The host name or API address of the HTTP proxy host.

Use null to force the direct connection instead of using proxy. If this value is null, all other parameters are ignored.
port

TCP port of the proxy host.
user

The user name to be used in case the proxy requires authentication. For anonymous proxy this parameter must be null.
password

The password to be used in case the proxy requires authentication. For anonymous proxy this parameter must be null.

Details

The changes of the proxy configuration will take effect on all Quotes Manager instances created after calling this method.
