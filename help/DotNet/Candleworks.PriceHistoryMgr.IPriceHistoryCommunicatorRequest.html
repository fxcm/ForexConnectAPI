interface IPriceHistoryCommunicatorRequest

Brief

The price history request object.

Details

The request object can be created using the IPriceHistoryCommunicator.createRequest() method and sent using the IPriceHistoryCommunicator.sendRequest() method.

The type defined in the pricehistorymgr_net.dll assembly. The namespace is Candleworks.PriceHistoryMgr.

Public Methods

getFromDate

Gets the oldest date/time of the requested history.

getInstrument

Gets the instrument.

getQuotesCount

Gets the maximum number of the requested bars/ticks.

getTimeframe

Gets the timeframe of the requested history.

getToDate

Gets the newest date/time of the requested history.
