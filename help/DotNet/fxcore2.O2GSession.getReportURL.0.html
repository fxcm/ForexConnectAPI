public method O2GSession.getReportURL

Brief

Gets Combined Account Statement (CAS) report URL.

Declaration
C#
string  getReportURL (string accountID, DateTime dateFrom, DateTime dateTo, string format, string langID)

Parameters
accountID

The Account ID the report is requested for.
dateFrom

The start date of the report statement period.

The specified date is used as the start date of the report period from the time the trading day begins, regardless of the specified time.

The parameter is optional. If it is null, the report is generated since the account opening date.
dateTo

The end date of the report statement period.

The specified date is used as the end date of the report period to the time the trading day ends, regardless of the specified time.[bbr]
The parameter is optional. If it is null, the report is generated up to today.
format

The output format of the report.

Possible values:

HTML

HTML format.

XML

XML format.

PDF

Adobe PDF format.

XLS

Microsoft Excel XML document format.

The parameter is optional. The default value is HTML.
langID

The language and the locale of the report.

Possible values:

enu

English

jpn

Japanese

fra

French

esp

Spanish

cht

Chinese Traditional

chs

Chinese Simplified

rus

Russian

The parameter is optional. The default value is enu.

Returns

  • If successful, the URL which can be used to load the report using the HTTP/GET command. The URL is valid only during the current session.

  • If unsuccessful, an empty string.

Details

The date and time in the report can be either in the UTC time zone or in the time zone of the server. See O2GSystemPropertiesReader for details. If the value of SERVER_TIME_UTC property is UTC, the date and time in the report will be in the UTC time zone. Otherwise, the date and time in the report will be in the time zone of the server. The time zone of the server can be checked in the BASE_TIME_ZONE property.
